# Illustro

**一枚絵の制作体験において、既存の主要ペイントアプリを上回ることを目指すペイントアプリ。**

目標は、描きたいものを、余計な操作や待ち時間に妨げられず、思いどおりに描ける環境を実現することです。

> **設計判断の優先順位**
> 1. 直感的な操作 — 説明なしでも自然に操作できる。
> 2. 使いやすさ・軽さ・応答性 — 操作を待たせず快適に制作できる。
> 3. 多機能性・表現力 — 高度な一枚絵の制作に必要な機能を幅広く備える。
>
> **機能を削って簡単にするのではなく、多機能でありながら直感的に使えることを目指す。**

## 全面再制作の進行順序

以下の**4段階をこの順番で**進めます。

1. **作るものを決める** — 機能・UI・操作体験・ユーザー要求を整理し、製品としての理想像を明確にする。
2. **軽量化の仕組みを設計する** — 理想の操作体験を実現するため、軽さ・体感応答性・処理効率を支える仕組みを検討する。
3. **設計図を描く** — 決定した要求と軽量化方針を踏まえて、各機能・構造・連携の具体的な設計図を作成する。
4. **実装する** — 設計図に基づいて制作し、実際の操作体験が要求を満たすか検証する。

現在は **第1段階「作るものを決める」** です。具体的な内部システム、技術構成、従来の実装順序を先に確定しません。前段階を飛ばして実装を始めません。

## 基本方針

- ユーザーの操作を最優先し、描画中・描画直後・内部処理中もキャンバス操作や次の操作を待たせない。
- 内部処理の完了より**体感上の即応性**を重視する。ただし画質・正確性・編集結果の整合性を犠牲にしない。
- キャンバスを作品のために広く保ち、直接操作・ジェスチャー・ショートカットなど複数の自然な操作手段を用意する。
- 優れた既存アプリから積極的に学ぶが、独自性や機能の寄せ集めを目的にしない。
- **旧Illustroの内部構造・採用技術・実装順序を引き継ぐ義務はない。** ただし明示されたユーザー要求を理由なく削除・変更しない。
- 「動く実装ができた」と「理想の制作体験を満たした」は別の判定とする。
