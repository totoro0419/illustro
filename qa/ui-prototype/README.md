# Illustro UI導線プロトタイプ

**設計試作。画像処理本体・Native保存・製品性能の実装ではありません。**

[`index.html`](index.html)をブラウザで開く。単体で実行でき、外部JS・フォント・通信は不要。GitHubのコード表示は実行ページではないため、公開プレビューは[案内](../../docs/product-architecture/PREVIEW.md)へ。

1. 左ツールを切替。右WorkspaceのBoxを開閉し、幅を境界または＋/−で変更する。
2. 左下「全機能」→カテゴリ→機能。上部検索では目的・名称・IDを入力。関連機能の行から横断する。
3. 右下Layersで拡張一覧、Undo／Redo／表示反転。QuickはCanvas右下から開く。
4. 上部「…」の操作確認でPC／タブレット／スマートフォンの表示枠を切替。制作フローの手順を選べる。
5. 選択／変形や機能詳細で候補開始→設定入力→適用／取消。未適用Sessionと作品Undoの違いを試す。
6. 「正式計算中を試す」で人工待機3秒。ナビ、Undo、模擬保存、別層選択を試す。保存要求後のUndoで固定された保存対象が変わらないことを状態モデルで扱う。

模擬保存はメモリ内の版固定で、ファイルやIndexedDBへ書き込まない。再読込で試作の編集は消える。試筆はSVGの例示、消しゴムは紙色の線であり実画素の消去ではない。図形/効果/文字/色管理/247処理本体、Panel持出や永続Workspace等は入口・契約のみ。実装済みとの誤解を防ぐため、試作の適用と保存には模擬と表示する。

生成・検査は[設計入口](../../docs/product-architecture/README.md)参照。`routes.js`と`index.html`は生成物。修正は原典を変えず、`tools/build_ui_routes.py`、`shell.html`、`style.css`、`model.js`、`app.js`へ。
