# Illustro C03〜C10 品質調査・修正事項 全体台帳

最終更新：**2026-11-16**（日本時間）

**目的：** このチャット内のC03〜C10独立品質調査で発見した欠陥・疑義・改善案を、今後の修正担当がそのまま利用できるよう整理する。実装や正式仕様には変更を加えていない。指摘が修正・解決済みであるとは主張しない。

## 1. 6大思想と判断順位

1. **直感的操作（最優先）**：ペン・指で最も自然に操作でき、画面上の作品を直接編集できる。
2. **使いやすさ・軽さ（次点）**：操作中・入力直後・編集処理中も待たせない。
3. **多機能性（次点）**：一枚絵の制作のために必要な表現と編集能力を備える。
4. **競合の優れた方式の採用**：CLIP STUDIO PAINT、Procreate、Krita、ibisPaint等の公式に公開された方式から学ぶ。
5. **柔軟な設計改善**：現在の設計に固執せず、必要なら互換性リスクを評価したうえで根本から直す。
6. **競合を超える完成度**：直感性・正確性・品質・制作時間を実測して改善する。実測前に「競合超え達成」と断定しない。

**重大なデータ消失・作品破損・保存不整合は①〜③に先立ち対応する。** 修正容易さだけで優先度を決めない。
