# Illustro — 全面再制作に向けた基本理念・設計思想

> **位置づけ：製品全体の最上位方針**
>
> 2026-10-27にユーザーが提示した基本理念を記録したもの。下位の機能設計・UI設計・技術設計・実装判断は、この方針に従う。

## 1. 最重要目標

**Illustroを、一枚絵の制作体験において既存のあらゆる主要ペイントアプリを上回るアプリにする。**

目指すのは、ユーザーが描きたいものを、余計な操作や待ち時間に邪魔されず、思いどおりに描ける環境である。

すべての設計判断は、次の優先順位に従う。

1. **直感的な操作** — 説明なしでも自然に操作できる。
2. **使いやすさ・軽さ・応答性** — 操作を待たせず、快適に制作できる。
3. **多機能性・表現力** — 高度な一枚絵の制作に必要な機能を幅広く備える。

機能を削って簡単にするのではなく、**多機能でありながら直感的に使えること**を目指す。

## 2. 絶対に守る設計思想

- **ユーザーの操作が最優先。** 描画中・描画直後・内部処理中でも、キャンバスの移動・拡大・縮小・回転や次の操作を待たせない。
- **体感速度を最重視。** 内部処理が終わっていなくても、操作した瞬間に期待する反応が得られることを目指す。単なる処理時間の短縮では不十分。
- **描画品質を妥協しない。** ブラシの追従性、筆圧、入り抜き、線の自然さ、質感、補正、表現力を徹底的に磨く。
- **正確性を犠牲にしない。** 線の消失、位置ずれ、不自然な変化、表示不良、編集結果の破損を許容しない。
- **ユーザーに余計な操作を要求しない。** 必要な操作へ自然に到達でき、直接操作・ジェスチャー・ショートカットなど複数の方法を活用できるようにする。
- **作品を主役にする。** UIはキャンバスをできるだけ広く保ち、必要な機能に素早くアクセスできる構成にする。
- **自由に試行錯誤できる。** Undo・Redo、非破壊編集、選択・変形、保存・復元などを快適に利用できるようにする。
- **独自性を目的にしない。** 既存アプリの優れた仕組みは積極的に参考にし、不足している部分を改善する。

## 3. 特に重視する機能と体験

- **キャンバス：** 描画状態に左右されない自由な操作。描画中の線も作品と一体となって動く。
- **ブラシ：** Gペン・鉛筆などの基本品質を極め、多彩なブラシ、細かな調整、強制入り抜きなどを備える。
- **UI：** 明るいAurora系デザイン、オレンジ寄り黄色のアクセント。左にツール、右に調整可能なWorkspace、中央に広いキャンバス。クイックコントローラーも重視する。
- **編集：** レイヤー、選択、変形、クリッピング、非破壊編集、高速Undo・Redoなどを直感的に扱えるようにする。
- **線画・塗り：** 線の接続や閉領域を理解し、隙間補完や塗り分けを支援する高度な線画レイヤーを目指す。
- **作品管理：** 自動保存、作品一覧、確実な復元、書き出し、オフライン利用を重視する。
- **対応端末：** PC・タブレット・スマートフォンそれぞれに適した操作環境を提供し、特にペンと指を併用するタブレットでの快適さを重視する。

## 4. 参考にするアプリ

ibisPaint、CLIP STUDIO PAINT、Procreate、Krita、Photoshop、Affinityなどを積極的に研究する。

単純な模倣や機能の寄せ集めではなく、各アプリの優れた部分を一枚絵の制作体験という共通目的のもとで調和させる。

## 5. 全面再制作における原則

**過去の実装ではなく、ユーザーの理想を引き継ぐ。**

旧Illustroの内部構造、採用技術、実装順序には拘束されない。一方、ユーザーが明示した要求やこだわりを、理由なく削除・変更してはならない。

また、実装が動いたことと、望んだ操作体験が実現したことは区別する。合格はユーザーの要求を実際に満たした場合に限る。

現段階では具体的な内部システムを決めず、まず製品全体の設計思想、操作体験、機能の理想像を固める。

**最終原則：技術や内部処理の都合にユーザーを合わせるのではなく、ユーザーの理想の制作体験を実現するために技術を選択する。**
