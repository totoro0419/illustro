**あなたはユーザーのWindows PC上のChatGPTデスクトップアプリで、Work locallyとして実行します。クラウドブラウザーや別の仮想PCではなく、このWindows PCのブラウザーを実際にクリック・入力・ドラッグしてIllustroの234機能を検査してください。**

最初に `docs/device-audit/PC-SETUP.md` の手順で、ローカルWorkとアプリ内ブラウザー（または許可されたChrome）によるクリック・キーボード入力・キャンバス上の描画が可能か確認してください。許可が必要なら正規の許可画面を使い、使用を拒否されたら無理に迂回しません。**PCの実操作ができなければ、クラウド上で検査したことにせず接続状況を報告してください。**

接続後、`docs/device-audit/WORK-EXECUTION-ROADMAP.md` と `docs/device-audit/work-steps/00-BOOT.md` だけ読み、P00→P12の102操作を順に行ってください。検査用ZIPがローカルにあれば `docs/device-audit/QA-FIXTURES.md` に従い使用。**234機能の使い勝手**を実際の操作で「使える・使いづらい・使えない・未検査」と判定し、「使いづらい」には問題点と「こうしてほしい」を1〜2文残す。コードや機能表示だけでは合格にしない。

結果は `01-RESULTS.csv`、問題は `02-DEFECTS.md`、最後に完了した操作は `WORK-RUN-PROGRESS.md` に記録。各P終了時にGitHubのこの検査準備ブランチへまとめて保存し、次の台本1ファイルだけ読んで続ける。アプリ本体・R2 PR #110・公開版は変更しない。

5時間の使用量枠1回で検査を終えるため、操作の繰り返し、長文報告、不要なコード調査・仕様証明・アプリ修正をしない。見つからない入口は該当パネル→機能一覧→検索を各1回だけ探し、問題なら記録して次へ。同じエラーは原則1回だけ再試行。デバイス非対応や素材不足は理由付き未検査とし、合格にしない。**最後の20分は結果保存・GitHub再取得・234行の整合性確認を優先する。**

234件の判定件数、問題点と改善案、未検査理由、実際に操作した端末・ブラウザーを簡潔に報告してください。途中の確認質問は不要ですが、PCへの正規の操作許可が必要な場合は画面の許可操作を尊重してください。
