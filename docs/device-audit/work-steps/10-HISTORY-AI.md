# P10｜履歴・操作セット・記録・補助

目安19分／8操作／18機能。本番のブラウザー操作は未実施。

**開始位置：** Aの履歴を残し右履歴/操作セット、すべての機能→履歴・自動化を使う。

**判定**：使える＝実操作で問題なし。使いづらい＝使えるが手間/重さ/品質に不満（原因と「こうしてほしい」1～2文）。使えない＝入口がない/無反応/絵がおかしい。未検査＝未実施・機器/ブラウザー/資料の制約。コードにあるだけで使えるにしない。

**入口の探し方**：指定パネル→「すべての機能」のカテゴリ→「機能を探す」の順に各1回。無ければ原則使えない。原因調査や実装修正は禁止。すでに確認した共通操作は再実施せず、各ID固有の振る舞いだけ見る。
