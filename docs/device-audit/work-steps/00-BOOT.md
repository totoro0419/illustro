# P00｜起動と基準作品

目安10分／6操作／9機能。本番操作はまだ未実施。

**開始位置：** R2公開URLのホームから開始。作品A=白背景1200×900、B=小さな透明作品。

**共通の判定**：使える＝実操作で普通に使える／使いづらい＝操作性・重さ・画質の不満と「こうしてほしい」を1～2文／使えない＝入口なし・反応なし・結果がおかしい／未検査＝本当に未実施または機器・ブラウザー・外部ファイル等の制約。マウスでペン・指入力を合格にしない。使える時は原則判定のみ記録。

**探索は各機能1往復まで**：指定パネル→「すべての機能」の該当カテゴリ→「機能を探す」でラベルを検索。無ければ「使えない」、操作できない外的条件なら「未検査」。無制限な試行・コード解析・実装修正は禁止。結果のCSV保存はこの段階の最後にまとめる。
