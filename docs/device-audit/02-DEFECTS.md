### 本番検査で発見した問題

Windows PCのEdgeで、指定Vercel版を実操作した結果。公開版コミットは未確認。

- D-001｜P00-03｜CAN-004｜1200%でピクセルグリッドをON→OFF→全体表示→作品Bを作成しても格子が全面に残る。再読み込みして作品Aを開き直すと消えた。OFFや表示倍率低下で格子を即時解除してほしい。使えない・現行版で再現。
- D-004｜P00-05｜CAN-009｜制作画面の「作品」に作品情報がなく、「機能を探す」の初期候補「作品の情報」は無効だった。「その他」→「ドキュメント・編集・出力」からはDPI変更とテンプレートの保存・再利用ができた。作品メニューと検索にも同じ入口がほしい。使いづらい。

- D-005｜P01-04・P01-13｜BRU-005・WET-006｜ブラシ設定と混色パネルで設定は変えられたが、独立した試し描き欄は見つからず、機能検索「試し描き」も該当なし。作品に反映する前に設定の違いを比較できる欄がほしい。使いづらい。

- D-006｜P02-05｜FIL-001｜色レイヤーに塗るとき、処理結果を待たず次の領域を押すと「塗る対象が変わりました」。閉じた四角を単独で押し処理完了を待つと塗れた。現在処理中の場所を示し、続けて押した場所を順に処理してほしい。使いづらい。
- D-007｜P02-05｜FIL-002｜1200×900、全体表示77%程度。10pxのミリペンで描いた四角の角に画面上10px程度の隙間を作り、線画レイヤーを参照、別の色レイヤーを対象、隙間補完を18pxにして内側をクリックした。内側と外側のほぼ全域に漏れた。設定幅内の隙間は塞ぎ、外側まで漏れる場合は適用前に分かるようにしてほしい。使えない。
- D-008｜P02-06｜FIL-004｜同じ色モードで四角を横断してドラッグすると、四角間を通った部分から背景も塗られた。閉領域内だけを連続塗りする選択肢がほしい。使いづらい。
- D-009｜P02-05｜関連 FIL-002・UNDの履歴確認予定｜隙間補完で漏れた直後、作業を終了しても下部の「元に戻す」が無効。Ctrl+Zで漏れが戻り、ボタンが再び有効になった。塗り確定時にUndoボタンを更新してほしい。
