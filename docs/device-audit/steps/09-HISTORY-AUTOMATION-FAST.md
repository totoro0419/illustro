# Illustro R2 実機｜09-HISTORY-AUTOMATION【省量版】

章内では同じ画面と検査用作品を使い回す。新機能の品質条件を省かず、共通保存などの重複動作は代表シナリオで実行する。

### AI-001｜選択・領域の補助［重点］
- [ ] 1. 既存の選択範囲を用意し、選択補助を明示起動する
- [ ] 2. 候補の追加・削除を行い、適用せず取消した場合に作品が変わらないか確認する
- [ ] 3. 候補を採用し、Undoで選択結果が戻るか確認する
**期待結果：** 明示起動、入力範囲、候補/修正/取消、非AIの手動操作を維持
**画面の確認：** 明示起動、候補を重ねて採用/取消、通常選択併存
**固有の保存・取消：** 採用を一Undo、結果と手修正を保存
**問題の基準：** モデル無効でも手動制作可能、誤境界を確定事実として表示しない
**評価：** AI-001｜未検査（操作後に変更）

### AI-002｜色・陰影の候補［重点］
- [ ] 1. 異なる色の領域を2つ作り、彩色補助を開く
- [ ] 2. 候補色を比較し、選択した候補だけ適用する
- [ ] 3. 誤った候補を取消して元の作品が保持されるか調べる
**期待結果：** 既存絵・資料・パレットに基づく案を別候補として比較
**画面の確認：** 別案サムネイルと作品上比較、採用まで元不変
**固有の保存・取消：** 別層/分岐へ採用、一Undo
**問題の基準：** 勝手な完成代行を中心にしない。提案の根拠と不確実性を示す
**評価：** AI-002｜未検査（操作後に変更）

### AI-003｜整理・修復の候補［重点］
- [ ] 1. 孤立した小さい点と連続する線を描き、整理・修復候補を実行する
- [ ] 2. 不要な候補は却下し、必要な候補だけ採用する
- [ ] 3. 誤って主要な線を消さないか確認する
**期待結果：** 層整理・名称・ごみ箇所の提案、描画順や見た目を無断変更しない
**画面の確認：** 候補一覧から一部採用、修正箇所を先に強調
**固有の保存・取消：** 一採用集合一Undo、元順序と名称を保持
**問題の基準：** 層の合成順を無断変更しない、誤検出は局所拒否
**評価：** AI-003｜未検査（操作後に変更）

### AUT-001｜記録・編集・再生［重点］
- [ ] 1. 操作記録・一括処理画面を開く。「記録・編集・再生」に対応する操作を選ぶ
- [ ] 2. 操作入口で「マクロ記録バー」の操作を行う
**期待結果：** 開始/停止、対象・パラメータ、並替/無効化、記録不可を事前表示
**画面の確認：** 記録帯と記録不可の印、手順の並替/編集
**固有の保存・取消：** マクロ定義は素材保存、記録操作は作品変更と区別
**問題の基準：** 非記録操作を黙って省略しない。再生の対象を先に表示
**評価：** AUT-001｜未検査（操作後に変更）

### AUT-002｜実行時パラメータ・対象指定［重点］
- [ ] 1. 操作記録・一括処理画面を開く。「実行時パラメータ・対象指定」に対応する操作を選ぶ
- [ ] 2. 操作入口で「実行前の対象と値」の操作を行う
**期待結果：** 特定レイヤー番号へ無言適用せず、現在対象/指定対象を確認
**画面の確認：** 実行前に対象名と可変項目だけ提示
**固有の保存・取消：** 参照は意味的対象として保存、層番号の偶然一致に依存しない
**問題の基準：** 対象欠落は停止/指定し直す、別層へ無言適用しない
**評価：** AUT-002｜未検査（操作後に変更）

### AUT-003｜実行比較・失敗・取消［重点］
- [ ] 1. 「候補プレビュー」を開く・実行する
- [ ] 2. 続けて「実行/取消」を選択・実行する
**期待結果：** 一実行一Undo、失敗は全体取消を標準、途中採用は明示選択
**画面の確認：** 処理手順と失敗箇所を表示し取消を常設
**固有の保存・取消：** 一実行一Undo、失敗標準はその実行を全取消
**問題の基準：** 後続の独立編集を巻き戻さない。外部副作用は自動Undoと約束しない
**評価：** AUT-003｜未検査（操作後に変更）

### AUT-004｜バッチ出力［重点］
- [ ] 1. 操作記録・一括処理画面を開く。「バッチ出力」に対応する操作を選ぶ
- [ ] 2. 操作入口で「一括出力一覧・停止」の操作を行う
**期待結果：** 出力コピーを標準、上書き先と失敗項目を記録
**画面の確認：** 実行予定一覧と項目別状態、停止/再試行
**固有の保存・取消：** コピー出力標準、原作品不変、結果記録
**問題の基準：** 一件失敗を隠さず残りを選択継続。上書きは別明示
**評価：** AUT-004｜未検査（操作後に変更）

### AUT-005｜高速入口・共有［重点］
- [ ] 1. 操作記録・一括処理画面を開く。「高速入口・共有」に対応する操作を選ぶ
- [ ] 2. 操作入口で「検索から追加」の操作を行う
**期待結果：** Quick Menu/キー/検索/素材登録、依存を確認
**画面の確認：** 検索結果から固定登録、用途名とショートカット表示
**固有の保存・取消：** パックに必要依存を含める、受信後は実行前確認
**問題の基準：** 共有先の未対応コマンドを実行可能と見せない
**評価：** AUT-005｜未検査（操作後に変更）

### HIS-001｜Undo・Redo［重点］
- [ ] 1. 履歴パネルを開く。「Undo・Redo」に対応する操作を選ぶ
- [ ] 2. 操作入口で「常時ボタン・2/3指・キー」の操作を行う
**期待結果：** 一筆/一塗り/一ドラッグ/一処理の意図単位、対象名と履歴範囲を表示
**画面の確認：** ボタン/キー/ジェスチャーの意味を一致、戻る対象名を短く表示
**固有の保存・取消：** 一筆/一塗り/一ドラッグ単位、採用済データは同一結果へRedo
**問題の基準：** 処理中Undoは対象操作を指定して受理し、後続入力を取り違えない
**評価：** HIS-001｜未検査（操作後に変更）

### HIS-002｜履歴一覧・比較［回帰］
- [ ] 1. 「履歴一覧」を開く・実行する
- [ ] 2. 続けて「前後比較」を選択・実行する
**期待結果：** 開く/選択だけで作品を変えず、プレビュー→明示復元
**画面の確認：** 一覧選択は比較のみ、明示復元で作品へ。ナビは可能
**固有の保存・取消：** 比較はUndo外、復元は元現在を保護して一操作
**問題の基準：** 比較中の描画は分岐作成を明示し元案を失わない
**評価：** HIS-002｜未検査（操作後に変更）

### HIS-003｜名前付きSnapshot［回帰］
- [ ] 1. 履歴パネルを開く。「名前付きSnapshot」に対応する操作を選ぶ
- [ ] 2. 操作入口で「案を保存」の操作を行う
**期待結果：** 名前・メモ・縮小画像、全編集状態を保持し無断削除しない
**画面の確認：** Snapshot作成は受付時点を表示、後続編集を継続
**固有の保存・取消：** 編集可能な全状態を保持、名前付きは容量整理で無断削除しない
**問題の基準：** 作成失敗を成功サムネイルにしない。未確定編集は別保留として示す
**評価：** HIS-003｜未検査（操作後に変更）

### HIS-004｜分岐・比較・復帰［回帰］
- [ ] 1. 履歴パネルを開く。「分岐・比較・復帰」に対応する操作を選ぶ
- [ ] 2. 操作入口で「Snapshotから別案を作る」の操作を行う
**期待結果：** 古い状態から編集しても元案を保護、Redo経路の変更を通知
**画面の確認：** Snapshotから別案作成、横並び/交互比較、明示復帰
**固有の保存・取消：** 元経路を保持し新分岐を保存、単純Undoと区別
**問題の基準：** 古い状態から編集でRedoを失う場合は元案の保護口
**評価：** HIS-004｜未検査（操作後に変更）

### HIS-005｜部分復元・履歴ブラシ［回帰］
- [ ] 1. 履歴パネルを開く。「部分復元・履歴ブラシ」に対応する操作を選ぶ
- [ ] 2. 操作入口で「旧案から部分を復元」の操作を行う
**期待結果：** Snapshotの選択部分/層を現在へコピー、古い対象と座標差を確認
**画面の確認：** 復元元と現在の重ね、コピー層か局所筆を選択
**固有の保存・取消：** 復元は現在への新編集一Undo、過去全体を書換えない
**問題の基準：** 層削除/変形で対応しない場合は候補を表示し勝手に当てない
**評価：** HIS-005｜未検査（操作後に変更）

### HIS-006｜履歴の容量・保持範囲［回帰］
- [ ] 1. 履歴パネルを開く。「履歴の容量・保持範囲」に対応する操作を選ぶ
- [ ] 2. 操作入口で「履歴管理と保護状態」の操作を行う
**期待結果：** 固定案と一時Undoを区別、削除前に依存・復元可能範囲を提示
**画面の確認：** 失う時点/依存を一覧、整理前のバックアップ案
**固有の保存・取消：** 固定Snapshotと復元原本は通常キャッシュと区別
**問題の基準：** 削除でRedo/Timelapseが壊れる依存を隠さない。無制限永久保存は約束しない
**評価：** HIS-006｜未検査（操作後に変更）

### REC-001｜Timelapse記録と再生［重点］
- [ ] 1. 制作記録画面を開く。「Timelapse記録と再生」に対応する操作を選ぶ
- [ ] 2. 操作入口で「記録設定・再生」の操作を行う
**期待結果：** UIを含めず、削除素材/履歴整理で無言破損しない
**画面の確認：** 作品作成時の選択、後から開始はその時点からと表示
**固有の保存・取消：** 作品変化を記録しUIを含めない、記録依存を保存
**問題の基準：** 履歴整理/素材削除で再生を無言破損させない。記録既定はDEC-14
**評価：** REC-001｜未検査（操作後に変更）

### REC-002｜動画の範囲・速度・解像度［重点］
- [ ] 1. 制作記録画面を開く。「動画の範囲・速度・解像度」に対応する操作を選ぶ
- [ ] 2. 操作入口で「動画書出しプレビュー」の操作を行う
**期待結果：** 区間/停止時間圧縮/最終静止/解像度/透かしを事前確認
**画面の確認：** 長さと容量見積と再生プレビュー、出力
**固有の保存・取消：** 作品Undo外、出力時点固定、設定を保存
**問題の基準：** 高解像度で筆順/色が変わらない。未検証最大値を保証しない
**評価：** REC-002｜未検査（操作後に変更）

### REC-003｜記録の除外・機密資料［重点］
- [ ] 1. 制作記録画面を開く。「記録の除外・機密資料」に対応する操作を選ぶ
- [ ] 2. 操作入口で「記録対象チェック」の操作を行う
**期待結果：** 資料・UI・削除案の含有範囲、記録停止と既存削除を区別
**画面の確認：** 含有範囲を出力前に確認、除外プレビュー
**固有の保存・取消：** 停止は将来だけ、過去の削除は別明示で復元範囲を説明
**問題の基準：** 資料は既定除外。記録削除が作品本体を消さない
**評価：** REC-003｜未検査（操作後に変更）

### REC-004｜実作業時間［重点］
- [ ] 1. 制作記録画面を開く。「実作業時間」に対応する操作を選ぶ
- [ ] 2. 操作入口で「作品情報の時間欄」の操作を行う
**期待結果：** Session/Today/Total/Average、手動停止、推定と実測を区別、誤集計補正
**画面の確認：** 情報パネルで期間/推定方法を表示
**固有の保存・取消：** Offline集計、外部送信不要、補正履歴を保持
**問題の基準：** 開いているだけの時間は含めない。Idle閾値は表示し後で補正可能
**評価：** REC-004｜未検査（操作後に変更）
