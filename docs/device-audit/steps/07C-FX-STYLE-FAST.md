# Illustro R2 実機｜線画・模様・影・光彩【省量版】

作品Aを使用。同じ効果一覧を開いたまま順番に試す。効果ごとの固有調整と画質を確認し、同じ起動・保存操作を繰り返さない。

### FX-129｜網点・スクリーントーン［重点］
- [ ] 1. 効果一覧→「網点・スクリーントーン」を選択
- [ ] 2. 網点の大きさと角度を各1回変更し、原画像と100%で比較
- [ ] 3. 格子原点を動かして効果範囲を確認→確定
**期待結果：** 密度・線数・角度を指定。マスク・強度・前後比較・再編集を保持。
**画面の確認：** 実寸/100%で網点と原濃度を比較、格子原点を直接移動
**固有の保存・取消：** 網点設定と元濃度を保持、モノクロ出力と通常表示を分離。設定/入力版/Mask/順序をNative保存。適用一Undo、再度開いて同じ制御を編集。取消は今回の設定だけ戻す
**問題の基準：** 拡縮/回転でモアレを確認、lpiとpxを混同せず出力DPI反映。計算失敗は元像を保持し効果をエラー表示、低品質プレビューを確定結果と偽らない
**評価：** FX-129｜未検査（操作後に変更）
