作品Aを使用。同じ効果一覧を開いたまま順番に試す。効果ごとの固有調整と画質を確認し、同じ起動・保存操作を繰り返さない。

### FX-116｜ガウスぼかし［重点］
- [ ] 1. 効果一覧→「ガウスぼかし」を選択
- [ ] 2. 半径を小→中程度へ変え、100%表示で輪郭と透明端を比較
- [ ] 3. 適用→再編集→取消で設定と元画素を確認
**期待結果：** 半径でなめらかにする。マスク・強度・前後比較・再編集を保持。
**画面の確認：** 半径スライダーと100%部分/分割比較
**固有の保存・取消：** 画素層/Groupを入力に平滑化、出力Maskと入力の読み範囲を区別。設定/入力版/Mask/順序をNative保存。適用一Undo、再度開いて同じ制御を編集。取消は今回の設定だけ戻す
**問題の基準：** 透明色の暗縁/タイル境界禁止、表示ズームで半径が変わらない。計算失敗は元像を保持し効果をエラー表示、低品質プレビューを確定結果と偽らない
**評価：** FX-116｜未検査（操作後に変更）
