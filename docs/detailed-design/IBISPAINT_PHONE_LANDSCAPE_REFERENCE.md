# 第③段階 — ibisPaintを強く参考にしたスマホ横画面UI研究・試作

**状態：方向性は本人指定、最終の具体的な配置は未承認。** 2026-11-01に利用者は横持ちスマホのA/Bへの回答として「アイビスを強く参考にして」と指示。よって、従来のA（全面下部Sheet）とB（常時Dock）をそのまま無条件採用せず、一次資料を調査して**C案（ibisPaint型の主要操作バー＋必要時だけ現れる設定・レイヤー）**を試作する。

## 一次資料と確認した要素（2026-11-01）

- [ibisPaint公式「03. ツールバーとツール選択」](https://ibispaint.com/lecture/index.jsp?lang=ja&no=04) — メインツールバーはブラシ/消しゴム切替・ツール選択・設定・カラー・フルスクリーン・Undo・Redo・レイヤー・戻る。ツール選択はウィンドウ/ポップアップでアクセスでき、列数の調整項目も公式に掲載。
- [ibisPaint公式「188. レイヤーウィンドウ詳細」](https://ibispaint.com/lecture/index.jsp?no=156) — レイヤー一覧とClipping/AlphaLock/不透明度、レイヤー作成などは専用ウィンドウ。**常時出して動かせるフローティングレイヤーウィンドウは公式説明でタブレット/PC限定**であり、スマホ横画面の既定だと偽らない。
- [ibisPaint公式「07. Undoと消しゴム」](https://ibispaint.com/lecture/index.jsp?no=08) — Undo/Redoは頻出の主操作。Illustroでは更に作品Undoと候補Undoを意図的に分離する。
- [ibisPaint公式「設定ウィンドウ詳細」](https://ibispaint.com/lecture/index.jsp?no=81) — タッチUndo/Redoジェスチャーを選択可能。**Illustroのジェスチャー自体の採否や端末互換は別研究**。既定を勝手に変更しない。

## C案：Illustroスマホ横画面

| 位置 | 優先操作と理由 | 表示/作用範囲 |
|---|---|---|
| 画面下部・コンパクト操作バー | ブラシ/消しの迅速切替、ツール選択、太さ・設定、色、**作品Undo/Redo**、レイヤー、詳細、戻る | 主要入口は常時見える。44px以上の操作標的を優先。小画面では横スクロール可能なため全ボタンの常時可視を無条件保証しない |
| 左ツール | **横持ちスマホ時は非表示** | タブレット/PCの左Railは保持。ツールは下部からポップアップで選べる |
| キャンバス | Dock未表示時は横幅を最大利用 | 上下の最小操作帯を除く。正式描画・ペン入力・Undo品質について本試作は証拠にならない |
| レイヤー/色/詳細 | 必要時に画面右のコンパクトな一時パネルを開く。タップで閉じられる | **スマホ常設フローティング機能というibisPaintの公式主張ではない。Illustro独自の横持ちアレンジ**。通常は非表示 |
| ツール一覧 | 下部「ツール」から3列のポップアップを開き、選択後に閉じる | ibisPaintのツール選択ポップアップに着想を得る。左Rail非表示時も全ツール到達 |
| 太さ/設定 | 下部「太さ・設定」から既存のContextBarを一時展開 | 描画のための高さを常時占有しない |
| Transform等の未適用Session | 候補Undo/Redo・取消・適用を専用Session帯に表示 | 先に本人承認したUndo Aを守る。下部の作品Undo/Redoは候補Undoへ変化しない |
| Focus | Focusの色・層一時Panelの開閉後にFocusへ復帰 | 既に本人承認されたFocus Aを守る |

## A/Bに対する採否と今回の範囲

- Aの「普段はDockを閉じてキャンバスを広く保つ」は採る。ただし**全面下部Sheet一択を横持ちスマホへ押し付けず、横側のコンパクトな一時パネルに変更**する。
- Bの「Workspaceを常時占有」は採らない。細かい設定は必要時に開く。
- ibisPaintの**操作を集約する考え方**は強く参考にしつつ、色、文字、アイコン、レイアウト、ブランド、グラフィックの実物をコピーしない。Illustroの明るいAurora系配色・多scope Undo・多機能への入口を維持。
- タッチ時の端末/OS UIの違い、利き手、ホームバー、ソフトウェアキーボード、ペン/指同時操作、視線移動・誤タップ率は未実測。CSSシミュレーション結果を製品合格と扱わない。
