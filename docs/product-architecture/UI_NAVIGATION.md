# 画面構造・ナビゲーション・端末別設計

**位置・寸法・細部の形状はUIレビュー案。要求済みの基本構造と操作意味は固定。**

## 1. 固定するものと旧UIからの継承

旧UI実装の確認版：`illustro_old`の `milestone/M09-color-basics`、`e04d3e29ab162d487d0c774524323bf49c684a4d`。`apps/editor/src/ui/shell.ts` の `railTools`、`RIGHT_BOXES`、`shellMarkup`、`shell.css`、`shellBehavior.ts`、`aurora.css` と、`docs/ui/LEFT_UI_SPEC.md`、`RIGHT_UI_SPEC.md`、`COMPACT_UI_SPEC.md` を確認した。画像から未確認の挙動を補ってはいない。旧実装を実機で再実行したとの主張もしない。

| 領域 | 継承する意味・初期配置 | 今回の具体化 |
|---|---|---|
| 上部 | Home・作品名・保存・Workspace開閉 | 検索・Focus。保存状態の文字は短く、詳細へ開ける。書き出しはNative保存と別入口 |
| 左Rail | Brush／Eraser／混色／スポイト／Fill／Selection／Transform／Move | 順序を文脈で変えない。末尾の全機能は常に到達可能。短い画面ではツール部分だけスクロール |
| 中央 | 広いCanvasと直接操作 | 対象帯、必要な候補のハンドル、軽い表示コントロール。色評価の周囲は中立 |
| 右Workspace | 幅可変、独立折畳の12 Box | 枠を何重にも重ねず、区切り線と見出し。三つの常用Box以外は初期折畳 |
| 右下固定 | Layers／Undo／Redo／表示左右反転／表示上下反転 | Workspaceを閉じてもこの帯は残す。反転は作品画素ではなくViewだけ |
| Quick Controller | 明示表示入口、固定スロット | 試作は6スロット格子。形の最終採用ではない。自動再配置なし、閉じる入口あり |

古いPC/タブレットの12 Boxは保持。初期展開はレイヤー・色・ブラシ。別Boxを開いても既存Boxを勝手に閉じない。旧実装の344px、288–440pxを**このプロトタイプの調整値**として使用し、新製品の端末上限や最適幅と断定しない。幅境界ドラッグのほか＋/−と矢印キーを持つ。取消・pointercancelは変更前の幅へ戻す。

## 2. 画面・Panel・Tool・Contextの役割

| 種類 | 保持する情報 | 変更してはいけない情報 |
|---|---|---|
| Screen | ホーム、制作画面、復元候補 | 切替だけで画素を変更しない |
| Panel | レイヤー、色、ブラシ、プロパティ、資料、素材、効果、表示、履歴、自動化、作品、Workspace | 開く・検索・スクロールを作品Transactionにしない |
| Tool | 次の接触で何をするか、一時ツールの戻り先 | 接地済み筆の対象・設定を後から付け替えない |
| Context | 描画先／Mask／参照元／選択／未適用候補 | 選択表示OFFを選択無効とみなさない |
| Session | 固定原本、候補値、内部Undo、適用・取消 | 他対象で成立した編集を巻き戻さない |

レイヤー行では**行の選択、表示、ロック、内容、Mask**を別操作とする。選択中の描画先を対象帯へ反映。表示Soloと作品レイヤー表示の変更を別ラベルにする。ブラシ色は次筆用設定であり、選んだ色だけで既存画素を塗り替えない。

## 3. 機能を見つける・入る・戻る

常用操作はRail・対象帯・固定操作・上部から直接。詳細の通常導線は「Boxを開く→分類→機能」。全機能の補助導線は「全機能→カテゴリ→機能」。検索は「検索→入力→結果」で、機能名だけでなく目的・ID・原仕様の操作語でも一致する。台帳のステップ数は入口が見える基準画面から機能の詳細へ到達するための値で、設定入力や制作の完了までの回数ではない。Home新規の基準画面はHome。

30の製品カテゴリを7つの見出しに整理する。見出しは読解用でクリック階層ではない。カテゴリ内は機能行の平らな一覧。45件のFXには高度な名称を維持しつつ、初見向けの目的検索と元の9機能群の説明を残す。将来、色調整／ぼかし等の一覧内フィルターを追加する場合も深いメニューにはしない。

検索結果を選ぶと、対応するWorkspace Boxを明示的に展開し、機能名へFocus。結果には通常位置を併記し、検索だけで存在を覚えさせない。情報を見るだけでは重い処理を起動しない。詳細から「使う／候補を試す」を選んだ時点で対象を確定する。現在Toolは検索中も維持する。閉じる・Escapeで元の入口へFocusを戻す。

保留・対象外も全247件の台帳として見つかるが、説明のみ。製品の通常制作候補には有効ツールとして並べない。COL-010からはCOL-008/IO-007/IO-009、VEC-008からはVEC-005/006へ案内する。保留の名前を見せただけで実装・提供済みとは表示しない。

## 4. 対象帯と文脈操作

固定順は「Tool→描画先→主要設定→現在色→補助操作」。Fill時は参照元と塗り先を別表示。変形後描画時は「変形後の見た目／元内容」を明示。候補の適用・取消帯はCanvasの下端に置き、画面変更で隠さない。

Canvas上の右クリック／長押しは補助。対象帯の「対象の操作」から同じ内容を単指で開ける。対象が曖昧なら候補一覧を出し、勝手に最上層へ決めない。Contextは現在位置に表示しても項目の意味を変えない。個人の固定Quickスロットを文脈で差し替えない。

## 5. 端末別の投影

| 条件 | 主配置 | Workspace・確定操作 | 代替と復帰 |
|---|---|---|---|
| PC・広い窓 | 左Rail、中央、右インライン | 12 Box＋固定5操作。ドラッグ境界で幅調整 | キーは加速手段。画面ボタンでも全操作へ |
| タブレット横 | 同じ構造。ペン／指／キーボードを併用可能とする | ユーザーが折畳・開閉。対象帯とQuickはCanvas近傍 | 利き手反転はRail、Panel、Popup、Quickを一式に適用する設計 |
| 中間幅・縦持ち | Canvasに必要な幅を残せない時は閉じたWorkspaceを明示入口で開く | 対象IDと候補を保持して配置だけ変える | 回転・リサイズを作品Undoにしない |
| スマートフォン | 左Railを保持。上部はHome／保存／検索等のコンパクト表示 | 右Boxの意味を下部シートへ。下端Undo／Redo／色／層／設定 | 閉じると元Canvasへ。ジェスチャー必須なし。キーボード時はシート内容を縦スクロール、操作帯を可視に |

今回の試作では幅760px以下のコンテナをコンパクトへ切り替える。これは**試作の配置条件**で、端末を入力方法と同一視しない。実機ではvisual viewport・safe-area・pointer能力・接続ペンの状態を別々に扱い、ハードウェア能力の最終判定は後工程。

プロトタイプのPC／タブレット／スマートフォン切替は、同じUI状態を保持する表示枠の切替。端末エミュレーターや本物のAndroidペン試験ではない。左右反転・パネル持出／並替・Workspace永続復元等は該当する機能の入口と契約を確認できるが、すべての操作本体を実装したとはしない。

## 6. Focus・持出・復元

Focusは主要クロームを隠す。画面内のFocus解除、Quick、重大な保存失敗の入口を残す。未適用候補・対象は保持。OS全画面は別の操作で、Focusと同一にしない。

持出Panelは同一Panel IDの別投影。元の位置に「持出中」を残し、再Dock／前面へ／配置リセットを提供。文書版を複製しない。画面が縮んだ時は安全領域へクランプし、復帰不能な画面外へ保存しない。今回の試作では持出の処理本体は未実装。

## 7. 評価軸

| 軸 | 今回できる評価 | 実機・初見評価で閉じること |
|---|---|---|
| クリック | 台帳の段数と実UIの入口構造を照合 | 「やりたいこと」を知らされた時の迷いを含む総手数 |
| 視線・ペン移動 | 固定入口、対象近傍Quick、表示帯とCanvas距離の幾何計算 | 実視線・手の移動、疲労。幾何距離を視線追跡の実測と呼ばない |
| 誤操作 | 隣接する破壊操作、対象名・Mask・取消をレビュー | 実ユーザーの誤タップ率・意図しないTool切替 |
| 占有面積 | viewportに対するstage面積・Popup占有をDOMから計算 | 作品の重要部を隠す度合い、ペンの死角 |
| 発見 | 検索とカテゴリの両経路、通常位置の表示 | 名称を教えず目的だけ提示して到達できる率 |
| 中断 | 独立操作、Focusと候補の維持を状態モデルで確認 | 連続制作時の集中、気付き、作業時間 |

これらの合成点で作品破損・到達不能・保存誤表示を相殺しない。重大な矛盾は単独で不合格。初見ユーザーテスト未実施のため「説明なしで直感的」を達成済みとは判定しない。
