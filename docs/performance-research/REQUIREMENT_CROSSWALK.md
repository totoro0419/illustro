# 既存改善案・品質・非待機契約との対応

25案を単に言い換えたものとは区別し、各体験案が必要とする内部の比較課題を示す。原案の採否は変更しない。新しい性能達成報告ではない。

| 既存案 | 研究先 | 今回踏み込んだ比較/検証 |
|---|---|---|
| EXP-01 | R02, R07 | 受付から保存までの状態/時点境界。受理済編集はlatest-wins不可。 |
| EXP-02 | R01, R03, R11 | 時刻付き表示変換と筆の局所性、接地意味の二案比較。 |
| EXP-03 | R09, R02 | 対象解決をCommandと受理レコードへ接続しUI表示と一致。 |
| EXP-04 | R02, R09 | 依存競合の判定とsession差分取消、独立編集保持。 |
| EXP-05 | R04, R02 | 塗り再評価の参照版と同Undoへ統合できる期限。 |
| EXP-06 | R05, R08, R10 | 候補が参照する同一版と色/表示条件、比較cacheの予算。 |
| EXP-07 | R04, R11 | 同版区分照会と独立濃度Mask、面IDと手修正制約の比較。 |
| EXP-08 | R09, R14 | 軽い検索宣言と固定Command入口、初回実行の準備境界。 |

| EXP-12 | R04, R09 | 位相差分と判断が必要な制約の局所提示、確認総時間。 |
| EXP-13 | R09, R05 | 安い候補絞込と正確な被覆照会、GPU同期を含むhit費用。 |

| EXP-17 | R08, R06 | 不変根の共有と保持範囲、GCと保護pinの競合。 |
| EXP-18 | R07, R09 | 保存成功request IDと後続変更の区別、誤解の実利用者検査。 |
| EXP-19 | R13, R10 | 形式能力graphと損失/色/編集性の往復oracle。 |
| EXP-20 | R02, R13, R14 | 意味的対象の束縛、隔離マクロと外部副作用の分離。 |
| EXP-21 | R07, R02, R08 | 保存fenceと全依存の固定、prefixと後続根の別評価。 |
| EXP-22 | R01, R02, R07 | cancel/upを別状態にし観測済部分の救出と保留復元。 |
| EXP-23 | R09, R13, R10 | 不能理由をCommand能力判定から返し無断代替を防止。 |
| EXP-24 | R02, R08 | 対象Identity/生存世代/表示epochを分離、受理済と候補を別処理。 |
| EXP-25 | R14, R06 | 宣言/実行/活動依存の分離、cold/warm/未使用/熱の予算。 |
