# R05 — タイル全体とタイル内部分再計算を選択する基本方針

日付：2026-10-29
状態：ユーザー提案を踏まえた基本設計方向。処理アルゴリズム・実行速度・正式実装は未検証。

## 基本方針

効果・合成・再評価は**タイル単位を共通の管理粒度**とし、各タイルの中では**全体更新と部分更新**を状況に応じて選択できるようにする。単一の更新粒度を強制しない。

1. **タイル内部分**：変更が小さいときは局所矩形または必要画素のMaskを対象とし、不要な画素更新を省く。
2. **タイル全体**：変更が広い／複雑な依存がある／部分管理のコストが高いときにタイル単位の処理を選ぶ。
3. **複数タイル・全体**：広範囲効果や全体入力が必要な演算は、影響する他タイル／画像全体へ計算依存を伝播させる。タイル境界で結果を切らない。
4. **入力範囲と出力範囲の分離**：書き換える画素集合（出力dirty）と、その画素を計算するために読む集合（入力依存領域／halo／遠方参照）は別管理。局所出力だからといって局所入力に制限しない。
5. **中間結果の再利用**：同じ入力版・効果設定・色契約の中間結果は安全に共有・再利用できる余地を残す。変更された依存だけ失効させる。
6. **正確性優先**：ぼかし・変位・マスク・効果順序・色／αの結果を変える省略は認めない。部分と全体の選択条件は、実機での処理時間・固定費・メモリを後日比較して決める。

## 未決定

タイルサイズ、部分範囲の表現方式（矩形/Mask/スパン）、部分計算の閾値、GPU命令の切り方、全体効果の依存伝播方式、入力結果のキャッシュ構造、実際の速度優劣、正確性の検査手順。**今は方式の基本方向のみ確定し、試作・性能検証は後工程へ送る。**
