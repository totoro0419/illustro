# R12 — 水彩の高度な作り込みを行わない

日付：2026-10-30 JST
状態：**ユーザーによる基本方針確定**。詳細機能の採否・優先度は後工程で製品仕様と整合を確認。

## ユーザー決定

> 水彩は作り込まない。以上

## 基本方針

- 水分・顔料・紙の吸収・時間経過を精密に追跡する**高度な水彩物理シミュレーションは重点開発対象にしない**。水彩専用の複雑な進行/停止/再開制御、常時拡散計算などの研究・実装を現在の優先課題から外す。
- 基本的なぼかし、引きずり、混色など一枚絵に有用な**通常のブラシ効果まで一括削除する趣旨ではない**。必要な表現は既存ブラシ基盤の範囲で、軽く直感的に提供する方向とする。
- 非使用時は水彩関連の継続的なCPU/GPU処理・常駐データを発生させない。通常筆・キャンバス操作・保存・Undoを優先する。
- PR #1のWET関連機能をこの研究記録だけで正式に削除・置換したことにはしない。対象機能の優先度・対応範囲は製品仕様反映時に明示して整合を取る。
- 高度な媒体表現の精度評価・実装研究は、ユーザーが再度必要性を指定しない限り先送りする。
