# AI独立案 — 自由発案用カードとは別の資料

これは**研究仮説集**。各A/B/Cは比較案で、正式採用はゼロ。先に[課題カード](USER_RESEARCH_CARDS.md)だけ読める。ユーザーの発案は未回答のまま保存し、下案への同意を求めない。既存25案の体験目標を実行原理へ掘り下げたもので、名称の付け直しを革新の証拠としない。新規性/世界初は主張しない。

表の「効果」は条件が成立した場合の予測で実測性能ではない。「弱点/未確認」は各方式の反証点。全案を共通の[試験](VALIDATION_PLAN.md)で比較し、正しさを通過してから速度を評価する。E01〜06は[モデル結果](EXPERIMENT_RESULTS.md)の範囲だけ。
