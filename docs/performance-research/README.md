**R10主要アプリ比較・推奨方針（2026-10-30）：** [作品別の色空間・精度を維持し、不要な色変換と一時バッファを削減](R10_DESIGN_DIRECTION.md)。Photoshop/Krita/Procreate/CSP/Affinity/ibisPaint公式仕様を比較。基本方向を推奨し、詳細実装・性能は後日検証（ユーザー個別承認は未確認）。

**R11主要アプリ比較・推奨方針（2026-10-30）：** [元画像を保持する非破壊変形と表示位置での直感的な編集](R11_DESIGN_DIRECTION.md)。Photoshop/Krita/CSP/Procreate/Affinity/ibisPaintを比較。変形中も描ける構造を重視。複雑変形の逆写像とGPU性能は後日検証（ユーザー個別承認は未確認）。

**R12基本方針確定（2026-10-30）：** [水彩の高度な物理シミュレーションは作り込まない](R12_DESIGN_DIRECTION.md)。必要な基本ぼかし・混色は通常ブラシの範囲で扱い、非使用時の計算負荷を増やさない。原仕様との優先度整合は後工程。

**R13基本方針確定（2026-10-30）：** [必要部分からの段階的入出力と能力別の損失説明](R13_DESIGN_DIRECTION.md)。分割して読み込み・書き出し、外観/色/編集性の損失を区別して事前説明。原本保護を優先し、形式別の性能は後工程で検証。

**R14基本方針確定（2026-10-30）：** [高度機能の未使用時は演算・常駐を抑えて必要時だけ起動](R14_DESIGN_DIRECTION.md)。軽量入口と需要が明確な時の先読みを併用。使用中のフィル・選択・ぼかしは別途最適化。
