## REF-001 — 複数資料・グループ

- **原仕様**：[REF-001](../../product-planning/features/REF.md#ref-001)。原採否：採用推奨。読解対象節hash：`bfd3864634cf8112d93c31229232b5c43a3ebf3364b7ac9fceeabe5803632908`。
- **1 目的**：資料を見ながら描く。原画と独立した複数画像、グループ・保存・再配置。
- **2 必要操作・計算**：資料追加/資料欄へのドロップ。計算：画像decodeと資料集合の配置。
- **3〜5 負荷・応答・不要待ちの問題候補**：大画像全解像度decodeを同時起動すると描画用メモリを圧迫する。
- **6 不要仕事・繰返し、10 前提の問い**：資料表示に必要な解像度と元画像保持を分けられるか。
- **7 資源/待機の確認観点**：全常駐量・一時peak・転送量・保存pin。電池/熱は未実測。 / decode/encode・依存graph・一時buffer。取込/出力を描画資源と競合させない。 / 探索・配置・hit判定・状態更新・画面面積。確認/探し直しも操作コスト。

- **維持する固有条件**：画像読込中も作品編集継続。資料は通常画像書出しに含めない。再編集/Undo：配置と資料集合をNativeへ保存、資料編集は名前付きUndo。
