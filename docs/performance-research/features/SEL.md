## SEL-001 — 矩形・楕円・投げ縄・多角形

- **原仕様**：[SEL-001](../../product-planning/features/SEL.md#sel-001)。原採否：採用推奨。読解対象節hash：`b7935e07d400c103fda6aa017bffe8e86275de4ff76223e9beb903e94d203bdd`。
- **1 目的**：必要な部分だけ編集する。形を直接指定、Replace/Add/Subtract/Intersectを常時識別。
- **2 必要操作・計算**：選択ツールのモードボタン。計算：形状と濃度Maskの加減交差。
- **3〜5 負荷・応答・不要待ちの問題候補**：筆/多角形の中断を全選択解除にすると既存範囲を失い、全画面Mask更新は無駄。
- **6 不要仕事・繰返し、10 前提の問い**：今回の輪郭と開始時Maskを別に保持できるか。
- **7 資源/待機の確認観点**：原本・座標/変位場・字形/Mask。再標本化や全物体再構築の繰返しを比較。 / 探索・配置・hit判定・状態更新・画面面積。確認/探し直しも操作コスト。 / 操作列・依存記録・保留差分と待機量。依存のない操作まで待たせない。
- **8 操作の複雑さ**：直接操作の要求は「ドラッグ形状とモードを表示、多角形は点追加/一つ戻る/閉じる」。上の問題と併せて、確認/対象探索/やり直しを含む総タスク時間を比較。現時点で初見直感性を判定しない。
- **維持する固有条件**：中断時は今回の輪郭だけ取消、既存選択を失わない。再編集/Undo：一作成一Undo、濃度付き現在範囲を保存。
