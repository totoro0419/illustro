## SAV-001 — 作品一覧・検索・整理

- **原仕様**：[SAV-001](../../product-planning/features/SAV.md#sav-001)。原採否：採用推奨。読解対象節hash：`2a28fe31e504d903223c36f9840b1f0d46b99f0d6d3838a81bc4bda70eb74159`。
- **1 目的**：作品を見失わない。サムネイル/名前/タグ/フォルダー/並替/最近使用、破損項目を正常に見せない。
- **2 必要操作・計算**：ホームの作品一覧。計算：一覧メタデータ索引とサムネイル読込。
- **3〜5 負荷・応答・不要待ちの問題候補**：全作品を開いて縮小像生成すると起動が重く、古い縮小像で破損を隠す。
- **6 不要仕事・繰返し、10 前提の問い**：検証状態付き小型索引だけで一覧を始められるか。
- **7 資源/待機の確認観点**：保存I/O・圧縮・検証・旧世代保持。耐久性の保証は環境別に検査。 / 探索・配置・hit判定・状態更新・画面面積。確認/探し直しも操作コスト。 / 全常駐量・一時peak・転送量・保存pin。電池/熱は未実測。

- **維持する固有条件**：古いサムネイルに更新日時を併記、読込失敗は空作品に置換しない。再編集/Undo：整理メタデータは作品一覧へ保存、作品内の描画Undoとは別。
