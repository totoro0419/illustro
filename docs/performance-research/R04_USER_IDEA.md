# R04 — 接線方向と曲線の延長を用いた隙間認識（ユーザー発案）

日付：2026-10-29
状態：研究提案。方式採用・性能・精度は未検証。

## 発案

線画の隙間を、単なる端点間距離だけでなく、端点付近の傾き・曲がり方・自然に延長した位置を利用して検出する。ibisPaintの「すき間認識」を機能上の参考とするが、同アプリが同じ内部アルゴリズムを使うとは確認できていない。

## 研究する処理

1. 線端付近の画素から局所的な方向と曲率を推定する。
2. 直線外挿と曲線外挿を比較し、他の線端または線の途中に自然に接続する候補を生成する。
3. 距離、両側から見た方向、線幅、交差、領域がどう変わるかを比較する。
4. つなぐ・つながないを一時的な仮想境界として扱い、元の線画は変更しない。
5. 不確かな候補は自動接続を断定しない。手動修正は元の線画との対応情報を保存し、変更後に再評価する。

## 重要な失敗例

近接した別線を誤って結ぶ、意図的に開いた場所を閉じる、直線延長では曲線を間違える、交点に複数候補がある、線画の小さな変更が遠方の閉領域を変える。

## 比較と検証

距離のみ、距離＋接線、距離＋接線＋曲率＋領域構造を同じ線画で比較。適切な接続率、誤接続率、塗りの漏れ、修正回数、処理時間、編集後の安定性を測定する。高価な推論を全画素で繰り返さず、候補のある箇所を優先する。
