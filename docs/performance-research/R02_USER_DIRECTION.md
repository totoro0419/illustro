# R02 — ユーザー提示の仮線・本線分離とタイル単位確定方針（2026-10-29 JST）

判断ID：**R02-U01**  
状態：**ユーザー提示の設計方針。仮線の独立表示・低品質許容・本線タイル単位計算の方向を記録**。一筆の公開境界、複数筆の確定順序、Undo/Save時の適用規則は引き続き研究・検証待ち。  
関連：R01-U01（[既存方針](R01_USER_DIRECTION.md)）、R02、R03、R06。

## ユーザーが指定した基本方針

1. **仮線は作品キャンバスの正式データに合成しない。** 別レイヤーのような独立した表示として持ち、作品上に見えるように重ねる。画面上の合成は行えるが、そのことを正式レイヤー・画素データへの確定と混同しない。
2. **仮線は必要に応じて低画質でよい。** 仮線の目的は作業中の迅速な視覚的応答。正確な本線へ切り替わる際に、観察力の高いユーザーには線が後から変化したように見える場合があることを許容する。どの品質水準まで許容するかは未測定。
3. **本線は正確に、タイル単位で計算・確定する。** タイルサイズ、計算粒度、CPU/GPU分担、スケジュールは実測前に固定しない。
4. **本線が正式な作品に反映された後、対応する仮線を削除する。** 仮線を先に消して空白が生じたり、二重描画したまま残したりしない。部分反映か一筆単位の一括表示切替かは未決定。
5. **本線確定と指によるキャンバス操作はともに進行し続ける。** R01-U01の両立要求を維持し、指操作の継続を理由に本線確定を無期限に延期しない。

## R02で残る本質的課題

- **連続筆の意味的順序**：A→Bの順に描いたとき、Bのタイル計算が先に終わっても、同一の最終画素へはAの上にBが重なる必要がある。異なるタイル、レイヤー、効果・混色などの真の依存関係は区別する。
- **複数仮線の表示**：Aが未確定の間にBを描いた場合、独立表示を維持しつつユーザーの描画順と対象に従って見せる。仮線の削除は対応する確定内容の可視化と連動する。
- **タイルの計算完了と作品への公開を区別**：一部タイルだけが処理済みでも、作品内で不整合な線やUndo単位を露出しないこと。すべてのタイルを揃えて一筆で公開する方式と、整合したタイルだけ逐次公開する方式を比較する。
- **履歴・取消・保存**：一筆の意味的Undo、受理済編集の欠落防止、保存要求時点までの保護を維持する。仮線を正式確定済みとして保存しない。

## 未確定・未検証

- タイル単位の仕事分割が実GPUで描画更新を優先可能にするか、処理オーバーヘッドを含めて検証する。
- 「1筆の全タイルが終わったらまとめて公開」対「タイルごとに公開＋対応仮線を隠す」のUX、画質、整合性、遅延の比較を行う。**ユーザーはタイル単位の本線計算を指定したが、タイル単位の画面公開まで確定していない。**
- 低画質仮線の具体的な近似、色、太さ、入り抜き、長さ、透明度、タイル境界の許容範囲は未決定。
- 同一タイルへの連続筆、順序が重要な合成、Smudge/湿式/フィルター/構造更新は、タイル単位独立性を一般には保証できない。
- 実アプリ・Androidでの入力配送、表示追従、GPU/CPU負荷、確定遅延、二重表示、表示欠落は未実測。無制限の処理負荷で両立を保証できるとは主張しない。

## 次の決定点

一筆の本線を全タイルで計算し終えてから**一括して画面上の仮線と切り替える**か、正しいタイルから**順次画面反映し対応する仮線だけ消す**か。これをユーザーの直感性、途中表示の破綻、性能と一筆Undoの意味から比較する。
