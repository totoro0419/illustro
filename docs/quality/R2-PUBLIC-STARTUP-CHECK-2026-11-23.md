# R2公開版の起動と基本操作の検査

2026年11月23日（日本時間）。ChatGPT内蔵ブラウザーで公開URLを操作した。

- [操作した公開URL](https://totoro0419.github.io/illustro/r2-preview/)
- [公開コミットの照合](https://totoro0419.github.io/illustro/r2-preview/release.json) — `c30c9f7bdb0406953a91b5bcd5b80eb510760f20`
- [修正PR #110](https://github.com/totoro0419/illustro/pull/110) · [型検査・本番ビルド・公開 #25](https://github.com/totoro0419/illustro/actions/runs/45145833898)

修正前の公開版で起動エラーを再現。公開用ファイルのエラー位置を照合し、初回レイヤー表示（`renderLayers` → `updateContextBar`）で道具名の一覧を初期化前に参照していたことを確認した。参照に先立って道具名の一覧と処理状態を初期化し、保存領域の準備失敗とアプリ本体の起動失敗を個別に表示するようにした。保存用データベース、ブラウザー内ファイル領域、設定、オフラインキャッシュのR2専用名を維持した。Nodeで起動順序の再現と修正後の動作、模擬ストレージで元の名前のデータが保持されること、エラーの区別を確認した。公開処理は `r2-preview/` 内だけを更新した。

| 操作 | 実際に確認した結果 |
| --- | --- |
| 公開URLを開く | ホームが起動し、保存設定エラーの表示なし。公開中のコミットが修正コミットと一致した。 |
| 新しい作品・キャンバス | 512 × 384 pxで作成し、白いキャンバスが表示された。 |
| Gペン・太さ・色 | 16 pxの暗い青の線と、6 px・#F02633に変更した赤い線が描けた。 |
| 消しゴム・取り消し・やり直し | 線を消去し、取り消しで両方の線が復元、やり直しで消去部が再現された。 |
| レイヤー追加・描画 | Layer 2を追加して描画し、Layer 2を非表示にするとその線だけが消え、再表示で戻った。 |
| アプリ内保存・開き直し | 「アプリ内に保存済み」を確認。別タブのマイ作品から開き、保存した線と消去跡を確認した。 |
| 再読み込み | 別タブを再読み込み後、マイ作品から開き、描画と消去跡を目視で照合した。 |
| 端末への作品ファイル保存 | 「作品ファイルを作成しています。」まで確認。内蔵ブラウザーでは保存先を選べず、端末への書き込みは未確認。 |

WindowsのEdgeは最初の接続でMicrosoft Family Safetyの制限画面を表示したため、上記の公開版検査はChatGPT内蔵ブラウザーで実施。作成した検査作品のみを操作した。公開直後には `index.html` を直接開くと旧版のファイルが返ったため、操作確認は末尾が `/r2-preview/` のURLで実施した。
