# Illustro M01〜M10 全機能・連続操作検査手順（コード照合版）

- 作成日：2026-11-20
- 対象：旧M01〜M10で受け入れられた機能。C03〜C10など後発の機能は対象外。
- 一次参照：`milestone/M10-accepted-2026-11-12` の `apps/editor/src/main.ts`、`ui/shell.ts`、`ui/shellBehavior.ts`、`ui/homeShell.ts`、`color/panel.ts`、`brushAdvancedEditor.ts`、`brushDynamicsEditor.ts`、`brushStarterPresets.ts`、`brushCatalog.ts`、`docs/IMPLEMENTATION_CHECKLIST.md`、`docs/roadmap/C01_C17_ROADMAP.md`。
- 実行対象：最新のUI改善版にも適用できるよう、操作の意味で書く。UI改善後の表示名称は必ず現物と照合する。
- 状態：**検査手順の作成のみ。これらの動作に合格したという意味ではない。**

## この検査の使い方

1. 原則、一つの作品を連続使用して次の項目へ進む。明記された複製作品B・C・Dのみ例外。
2. 操作の各行に「実行できた／できなかった／画面に見当たらない／環境のため未確認」のいずれかを記録する。
3. 失敗時は、その時点の「選択していたツール・レイヤー・ブラシ・色・開いている画面・直前の3操作」を記録する。問題の再現に必要な範囲のコードだけ確認する。
4. 期待状態はテストの合格条件。コードにUI入口がない場合は、無理に達成したことにしない。
5. スタイラスの筆圧・傾き・ひねり、OSによるバックグラウンド終了、実機描画速度は対応環境がない場合「未確認」。
6. ブラシ先端等の組み合わせは技術上拒否されることがある。その場合はエラーを確認して次へ進む。
7. 保存場所とブラウザ内保護は別。削除操作は複製に限り、既存の本物の作品やストレージ全体は消去しない。

### 対象に含めない機能
投げ縄・矩形・多角形選択、選択範囲の追加／解除／反転、コピー／切り取り／貼り付け、マスク、レイヤー合成／結合／並び替え、塗りつぶし、文字、ベクター、定規、マクロ、資料などはM10時点での主要受入範囲外。後から開発されたC系の機能まで「M10合格機能」と誤認しない。

## 網羅性・境界

全33シナリオ・827操作。対象の10段階すべてを少なくとも一つ以上のシナリオで扱う。ここでの「全操作」は、M10の受入済み機能について、通常の作画と重要な解除・中止・復帰・連続切替の代表経路を網羅した検査項目を意味する。操作の組み合わせの数学的な全通りではない。
