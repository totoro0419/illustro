## 見つかった問題と再現手順

- **T052、T289 不透明度の数値入力が設定へ反映されない。** Gペン → 「ブラシを選ぶ」 → 「描き味を調整」 → 不透明度の数値欄に45または38を入力し、欄から離れる。数字が変わっても不透明度の設定表示は100%のままで、直後に描いた線の濃さが変わらなかった。同じ箇所のスライダーを40%へ動かすと、設定表示が変わり、重ねた線は下の色が透けた。T052は数値入力経路をFAIL、T289はスライダーで指定設定を実行できたためPASSとした。
- **T225 カラー履歴を消去する入口を確認できなかった。** 「色を選ぶ」→「パレット」で、カラー履歴欄、パレットの編集・管理、色の操作メニューを確認した。保存した色の削除ボタンは表示された。
- **T218〜T223 パレットJSONの再読込は未確認。** 「書き出す」は押せたが、この接続でダウンロードファイルを確認できなかった。「読み込む」でファイル選択要求が発生した。書き出したJSONを特定できず、読込後のパレットと描画は確認できなかった。
