# Illustro R2 Windows実機｜第4章：レイヤー・合成（17機能）

**実行指示：** 以下のチェックリストを上から順にマウス・キーボードで実行。各機能の判定は「使える／使いづらい／使えない」、環境で試せない場合は未検査。コード変更禁止。共通作品はインデックス記載のものを再利用。

## 4-A｜レイヤー・合成（17機能）

**画面の準備：** レイヤー一覧を開く。作品Aを使い、検査に必要なレイヤー・色面を残す。

### LAY-001｜追加・選択・描画対象固定　［重点／R2］

- [ ] **LAY-001.1.** レイヤー一覧を開く。「追加・選択・描画対象固定」に対応する操作を選ぶ
- [ ] **LAY-001.2.** 操作入口で「レイヤー＋/行タップ」の操作を行う
- [ ] **LAY-001.3.** 設定の「種別」「挿入位置」「選択層」「描画対象サムネイル」を順に変更し、初期表示との違いを確かめる
- [ ] **LAY-001.4.** 同じ操作を既定値と変更後の値で各1回行い、結果の違いを見比べる
- [ ] **LAY-001.5.** 操作を取消して元画像に戻し、もう一度実行して確定する
- [ ] **LAY-001.6.** 変更をUndoで戻し、Redoで再現できるか確認する
**期待する結果：** 新規は選択層直上、追加後選択、一筆の途中で描画先が勝手に変わらない
**画面で確認すること：** プラスで選択層直上へ追加して選択、対象帯も更新
**Undo・保存で守ること：** 層追加一Undo。筆中の対象変更は次筆から
**使いづらい／使えないとする例：** 非表示/マスク選択を明示、途中筆の出力が別層へ飛ばない
**記録欄：** LAY-001｜未検査（操作後に「使える／使いづらい／使えない」へ更新）
