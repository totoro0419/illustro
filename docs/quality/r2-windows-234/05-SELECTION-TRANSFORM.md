**実行指示：** 以下のチェックリストを上から順にマウス・キーボードで実行。各機能の判定は「使える／使いづらい／使えない」、環境で試せない場合は未検査。コード変更禁止。共通作品はインデックス記載のものを再利用。

## 5-A｜選択・クリップボード・変形（20機能）

**画面の準備：** 選択・コピー操作パネルを開く。作品Aを使い、検査に必要なレイヤー・色面を残す。

### CLP-001｜コピー・切取・貼付　［変更影響あり・標準／既存］

- [ ] **CLP-001.1.** 選択・コピー操作パネルを開く。「コピー・切取・貼付」に対応する操作を選ぶ
- [ ] **CLP-001.2.** 操作入口で「編集バー/キー」の操作を行う
- [ ] **CLP-001.3.** 設定の「Copy」「Cut」「Paste」「範囲」を順に変更し、初期表示との違いを確かめる
- [ ] **CLP-001.4.** 操作後、変更前と変更後の見た目を比較する
- [ ] **CLP-001.5.** 取消またはUndoで変更前に戻ることを確認する
**期待する結果：** 選択範囲/層/物体を明示、内部コピー失敗なら切取元を消さない
**画面で確認すること：** メニューから実行、貼付は選択層/Group直上へ新層/物体
**Undo・保存で守ること：** Cutは内部コピー成功後のみ元削除、一操作一Undo
**使いづらい／使えないとする例：** OS権限拒否でも内部Copy/Paste成立、元削除を先行しない
**記録欄：** CLP-001｜未検査（操作後に「使える／使いづらい／使えない」へ更新）
