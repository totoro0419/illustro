## 検査中に発見し修正した保存表示の不具合

[初回修正 `c30c9f7`](https://github.com/totoro0419/illustro/commit/c30c9f7bdb0406953a91b5bcd5b80eb510760f20)では、1200×900の作品に交差線を描き、800×600へ変更して保存を待ち、取り消して再読み込みすると、線の中央だけ表示された。変更直後と取り消し直後には線全体が表示された。

[保存修正 `c0afe57`](https://github.com/totoro0419/illustro/commit/c0afe578ddf385e970f2c192049aad41ce1e756d)では、寸法や描画領域の構成を変えた後は復元用の画像を全体から作り直す。寸法の合わない差分や旧形式の作業用画像を使わず、作品の記録から描画を復元する。異なる寸法の差分が入り込まないことを、模擬ストレージでも検証した。

[公開処理 #26](https://github.com/totoro0419/illustro/actions/runs/45148157938)成功。[公開コミット](https://totoro0419.github.io/illustro/r2-preview/release.json)が `c0afe578ddf385e970f2c192049aad41ce1e756d` と一致し、元の `index.html` でもホームが開いた。旧版で欠けていた2作品の線を修正版で再表示できた。同じサイズ変更→自動保存→取り消し→再読み込みを再実行し、交差する2本の線が欠けずに残った。
