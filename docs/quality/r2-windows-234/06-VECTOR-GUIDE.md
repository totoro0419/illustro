### GRA-001｜線形・放射・反射・角度　［重点／R2］

- [ ] **GRA-001.1.** グラデーション設定を開く。「線形・放射・反射・角度」に対応する操作を選ぶ

**使いづらい／使えないとする例：** 選択/マスク範囲と外側色を予告、透明端で暗い縁を出さない
