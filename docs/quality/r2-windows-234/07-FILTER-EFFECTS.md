**実行指示：** 以下のチェックリストを上から順にマウス・キーボードで実行。各機能の判定は「使える／使いづらい／使えない」、環境で試せない場合は未検査。コード変更禁止。共通作品はインデックス記載のものを再利用。

### FX-001｜色調整レイヤー　［重点／R2］

- [ ] **FX-001.1.** フィルターまたは効果の一覧を開く。「色調整レイヤー」に対応する操作を選ぶ
- [ ] **FX-001.2.** 「調整を追加」を開く・実行する
- [ ] **FX-001.3.** 続けて「比較」を選択・実行する
- [ ] **FX-001.4.** 続けて「適用」を選択・実行する
- [ ] **FX-001.5.** 設定の「調整種別」「全体」「クリップ先」「初期マスク」を順に変更し、初期表示との違いを確かめる
- [ ] **FX-001.6.** 同じ操作を既定値と変更後の値で各1回行い、結果の違いを見比べる
- [ ] **FX-001.7.** 操作を取消して元画像に戻し、もう一度実行して確定する
- [ ] **FX-001.8.** 変更をUndoで戻し、Redoで再現できるか確認する
**期待する結果：** 明るさ/コントラスト/レベル/カーブ/露出/色相彩度/自然な彩度/色バランスを再編集
**画面で確認すること：** 追加から対象と種類を選ぶ。具体制御はFX-101〜107
**Undo・保存で守ること：** 作成一Undo、元画素保持、個別調整欄を再度開ける
**使いづらい／使えないとする例：** 選択を作成時マスクへ固定、以降の選択変更へ追従しない
**記録欄：** FX-001｜未検査（操作後に「使える／使いづらい／使えない」へ更新）
