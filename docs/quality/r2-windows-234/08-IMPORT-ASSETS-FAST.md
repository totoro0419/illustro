# Illustro R2 Windows実機｜08-IMPORT-ASSETS【省量版】

章内では同じ画面と検査用作品を使い回す。新機能の品質条件を省かず、共通保存などの重複動作は代表シナリオで実行する。

### AST-001｜素材種別の管理［回帰］
- [ ] 1. 「素材一覧」を開く・実行する
- [ ] 2. 続けて「種別」を選択・実行する
**期待結果：** ブラシ/先端/紙/質感/パターン/グラデ/色/マクロ/Workspace/資料/図形を保持
**画面の確認：** 種別別サンプル、作品へ置く/設定へ使うを分離
**固有の保存・取消：** 資源の版と依存を管理、作品使用分は保持
**問題の基準：** 異なる種別を名前だけで自動置換しない
**評価：** AST-001｜未検査（操作後に変更）

**問題の基準：** 絞込ゼロと素材未取得を区別、隠した素材の解除口
**評価：** AST-002｜未検査（操作後に変更）

### IO-002｜PNG・JPEG・WebP［重点］
- [ ] 1. 同じ作品をPNG、JPEG、WebPで順番に書き出す
- [ ] 2. 3つの書出しファイルを再度開き、透明部・画質・寸法の違いが設定どおりか確認する
**期待結果：** 透明/背景/品質/可逆/ICC/サイズ/範囲/ファイル名を確認
**画面の確認：** 透明チェッカーと背景プレビュー、100%圧縮比較
**固有の保存・取消：** 固定時点からコピー出力、作品Undo外、プリセット保存

**評価：** IO-002｜未検査（操作後に変更）

### IO-003｜PSD・PSB互換［重点］
- [ ] 1. 2枚以上のレイヤーを含む作品をPSDへ書き出す

**期待結果：** 対応する画像・レイヤー・透明度を安全に交換

**固有の保存・取消：** 元Nativeを保護してコピー書出し
**問題の基準：** 全アプリ・特殊マスク/文字/効果の完全互換は今回の合格条件ではない
**評価：** IO-003｜未検査（操作後に変更）
