# Illustro R2 Windows実機｜第1章：起動・キャンバス・保存（18機能）

**実行指示：** 以下のチェックリストを上から順にマウス・キーボードで実行。各機能の判定は「使える／使いづらい／使えない」、環境で試せない場合は未検査。コード変更禁止。共通作品はインデックス記載のものを再利用。

## 1-A｜起動・キャンバス・保存（18機能）

**画面の準備：** ホーム画面またはキャンバスの表示・作品設定を開く。作品Aを使い、検査に必要なレイヤー・色面を残す。

### CAN-001｜新規作品　［重点／R2］

- [ ] **CAN-001.1.** 新規作品を開き、標準プリセットを選んで現在の幅と高さを確認する
- [ ] **CAN-001.2.** 幅1200・高さ900を指定し、背景を白と透明で切り替える
- [ ] **CAN-001.3.** 作成を一度取消してホームへ戻り、再度開いて作品を作る
**期待する結果：** sRGBで寸法・単位・DPI・背景を設定して新規作品を作る。
**画面で確認すること：** 寸法を入れると画素数と用紙比率を更新。作成で空作品、取消でホームへ
**Undo・保存で守ること：** 作成前は作品履歴なし。作成後は選択済みRaster1枚、属性を保存
**使いづらい／使えないとする例：** 省略した高度仕様を対応済みと誤表示しない。既存描画/保存を維持。
**記録欄：** CAN-001｜未検査（操作後に「使える／使いづらい／使えない」へ更新）

### CAN-002｜表示移動・拡縮・回転　［重点／R2］

- [ ] **CAN-002.1.** キャンバス中央から画面幅の約1/4をマウスで移動し、線と選択枠が一緒に移動するか見る
- [ ] **CAN-002.2.** 拡大・縮小・回転を各1回実行し、途中線と既存線の位置ずれがないか調べる
- [ ] **CAN-002.3.** 作画中または直後の表示操作で次の線が飛ばないか確認する
- [ ] **CAN-002.4.** 操作を取消して元画像に戻し、もう一度実行して確定する
**期待する結果：** 描画中・直後・全処理中にも作品と途中線を一体で動かす
**画面で確認すること：** 作品・途中線・選択・ハンドルが同じ表示に追従。ペン接地時の描線解釈はDEC-02比較待ち
**Undo・保存で守ること：** 表示移動は作品Undo外、文書ごとの表示位置を復帰
**使いづらい／使えないとする例：** 処理中も入力受付。誤線・座標飛び・後続筆欠落は不合格。非待機契約NB参照
**記録欄：** CAN-002｜未検査（操作後に「使える／使いづらい／使えない」へ更新）
