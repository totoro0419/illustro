## 3-A｜色・塗りつぶし・線画（27機能）

**画面の準備：** 現在色または色管理パネルを開く。作品Aを使い、検査に必要なレイヤー・色面を残す。

### COL-001｜色相環・HSV・RGB・HSL　［重点／R2］

- [ ] **COL-001.1.** 現在色を押し、HSVで赤→青、RGBで青→緑へ変更する
- [ ] **COL-001.2.** HSL等の切替があれば切り替え、表示色と新しい描線が一致するか確認する
- [ ] **COL-001.3.** 操作を取消して元画像に戻し、もう一度実行して確定する
**期待する結果：** 色相環と彩度明度面、正確な数値・色コードを往復
**画面で確認すること：** 輪と色面を直接操作、数値入力と相互更新。確定色と直前色を並置
**Undo・保存で守ること：** 色変更は作品Undo外、パレット登録で作品色として保存
**使いづらい／使えないとする例：** 範囲外数値を黙って切り捨てず表示。モデル切替で不要な色変化を起こさない
**記録欄：** COL-001｜未検査（操作後に「使える／使いづらい／使えない」へ更新）
