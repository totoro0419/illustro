# M07 — PC / Tablet UI: official product comparison and decisions
Date: 2026-10-10. Scope: public UI behaviors, not private rendering architectures.
Priority: intuitive use → responsive/low-distraction operation → breadth. CANONICAL owns Illustro choices; comparisons do not override it.

## Cross-cutting comparison / concrete engineering interpretation

| Concern | Reference benefit | Illustro M07 implementation boundary |
|---|---|---|
| Canvas size | Procreate Hide Interface; Krita Canvas Only; CSP collapsed palettes | Real Canvas remains mounted; Right stack can close and switches to overlay when <720 CSS px remains. Do not recreate renderer when closing. |
| Tool access | ibisPaint tool selector; CSP tool palette; Photoshop toolbar | Left rail Brush/Eraser enabled; six later tools explicitly disabled with reasons; All Features always pinned at bottom. |
| Panel access | CSP palette grouping, Krita Dockers, Photoshop panels | 12 stable semantic Box identities; scrollable stack; independent five fixed commands; independent Box state saved to workspace local storage only. |
| Layer access | ibisPaint Layer Window, CSP Layer palette | Same EditorController layer objects mirrored in compact Layers Box and expanded Layer Page. Opening Page does not change document. |
| Save access | CSP command bar, Photoshop workspace | Top Save -> .illustro; output format control stays separate. Reuse existing M05/M06 handlers and preserve recovery. |
| Tablet targets | CSP Studio/Simple tablet distinction; Procreate sidebar for hand access | Preserve PC density; increase functional target area for coarse pointer; pen can resize only on explicit grip. Actual stylus false-positive testing still required. |
| Workspace customization | Krita saved layouts, Photoshop saved workspaces, CSP movable palettes | M07 width and collapse remembered; M12 will own docking, presets, reorder, floating windows. |
| Accessibility | General desktop guidance plus project input-control spec | Icon-only names, visible focus, ARIA expanded/selected, disabled reason; no hidden hover-only route to essential actions. |
