# Illustro 第二ラウンド 機能別の実装状況

2026年11月23日。実装ブランチの `8a096723` の完成100件・部分実装43件から再開し、[計画PR #109](https://github.com/totoro0419/illustro/pull/109) の改訂条件を適用しました。実装は [Draft PR #110](https://github.com/totoro0419/illustro/pull/110) に集約しています。

判定の根拠は `docs/DESIGN_AUTHORITY.md`、`docs/product-planning`、[第2ラウンド改訂計画](https://github.com/totoro0419/illustro/blob/planning/round2-seven-groups-2026-11-22/docs/roadmap/ROUND2-REMAINING-7-GROUPS.md) と [機能ID別の条件](https://github.com/totoro0419/illustro/blob/planning/round2-seven-groups-2026-11-22/docs/roadmap/ROUND2-REMAINING-7-GROUPS.json) です。正式247 IDの内訳は保護91、今回実装143、今回対象外2、従来対象外11です。既存の品質指摘129件・利用者報告8件の割り当ては改訂計画にあります。

- `COL-007` と `AI-004` は利用者決定による今回対象外です。143件の集計から除外します。
- `WET-002`・`WET-005` は新しい筆跡を対象とする軽量方式、`WET-007` は従来の外観維持で判定しました。`IO-003` はPSD・PSBの基本交換、`IO-006` は現在対応しているEXR・AVIF入出力と対応環境のHEIF入力が範囲です。ICC・出力色確認・端末内AI補助は維持しています。
- 「完成」は操作・処理・設定と、その機能に必要なUndo・保存が実装でつながっている状態です。前回の完成100件の根拠を引き継ぎ、部分実装だった項目の実装と条件を確認しました。端末での受入結果は別です。
