# 要求と検証の対応

基盤の実装、機械で確かめたこと、実際のペンで確かめることを区別する。全体を完成・本番採用済みとは判定していない。最新の実行結果は `VALIDATION.md` を参照。

| 要求 | 現在の対応と証拠 |
|---|---|
| 1 大手アプリの調査 | `RESEARCH.md`。公式情報・設計判断・非公開部分を区別。 |
| 2 共通基盤 | `ARCHITECTURE.md`、共通設定・入力・描画・拡張境界。 |
| 3 入力 | `model.mjs`、`captureInput`。実入力、補正後の点、予測、離したときの情報を分離。 |
| 4 描画中と確定後 | `foundation-check.mjs` が描画中→ペンを離す→正式描画のGPU画像を比較。画面での自然さは実機確認。 |
| 5 予測 | `predictFoundation`。向き・減速・停止・筆圧低下で抑制。予測は保存禁止。外れたときの見え方は実機確認。 |
| 6 手ブレ補正 | 常時、速い動き、速度による増減、ブラシ別・共通を分離。描画後補正は明示的な編集API。 |
| 7 共通Dynamics | `evaluateDynamics`。入力と変更対象を対応づけ、曲線、範囲、足す・掛ける・置き換えるを使用。 |
| 8 筆圧 | 端末曲線→ブラシ曲線→独立した筆圧平滑化。太さ・濃さ・量・質感の変更。自然な反応は実機確認。 |
| 9 速度 | px/sでの対応づけ、速度による補正量変更。専用ブラシ分岐は不要。 |
| 10 入り | なし・実筆圧・距離/時間での人工的な入り。点・短線の保存も検査。 |
| 11 抜き | 実筆圧、描画中に決まる減衰。離した後に線を延長・細くしない。自然さは実機確認。 |
| 12 汎用Taper | 太さ・濃さ・塗料量・かすれの開始/終了曲線。中間は基本値・距離/時間対応づけで表現。自由描画の未知の終点を使う設定は拒否。 |
| 13 Tip | 円、楕円、矩形、画像マスク等。毛束は将来の描画拡張で扱う。 |
| 14 回転 | 固定角度、線の向き、任意対応のペン方向/軸回転、再現可能なランダム。角度境界は短い方へ補間。 |
| 15 間隔 | 太さ基準、絶対距離、対応づけ、時間間隔。インクと連続した質感/柔らかい線は点置き待ちを回避。 |
| 16 描画方式 | 連続インク、順番に重ねるスタンプ、連続した柔らかい/質感付きの面を同じ設定基盤で選択。 |
| 17 輪郭 | インクは解析的な1px輪郭処理、他形状は既存の複数点評価。描画中だけ粗い品質へ切り替えない。 |
| 18 濃さ/Flow | 一筆の濃さ、各押印の塗料量、上限付き/重ねるほど増える描画を分離。 |
| 19 Blend/Erase | normal/erase/multiply/screenの共通合成。消しゴムは色のある下地でGPU検査。 |
| 20 かすれ | 質感強度と筆圧/速度/乱数、開始/終了曲線。専門的な毛筆シミュレーションは未実装。 |
| 21 乱数 | 保存した2つのseedと固定した乱数系列。描画タイミングに依存しない。 |
| 22 散布 | 粒の数、半径、中心/外側への偏り、絶対/相対サイズ、回転。 |
| 23 質感 | tip/paper/strokeの別スロット、画像/手続き模様、縮尺・回転・向き・反転・最小強度・画像補間。同時使用は現在1スロットまで。 |
| 24 Brush Type | 種類と描画提供者の識別子。単色以外は明示的な拡張を要求し、完成済み扱いにしない。 |
| 25 水彩 | 別の描画提供者、設定拡張領域、資源参照、共通backend契約。混色/水/顔料は未実装。 |
| 26 Cursor | `cursorState`。現在の太さ・形・回転・色・濃さ・軸回転。表示UIは範囲外。 |
| 27 Preset | `SPEC.md`、`reference-brushes.json`。新形式と旧形式を別に保持。 |
| 28 一時変更 | `PresetState`。保存値と一時値を分離し、復元/ブラシ別/共通で切替。 |
| 29 Custom Pattern | 埋め込みマスク/質感画像と参照ID。編集画面は範囲外。 |
| 30 共有 | ブラシ一式の書出し/読込み、形式バージョン検査。QR/配布サービスは範囲外。 |
| 31 Shape/Ruler | `geometryContext` と `RealtimeSession.geometry`。先に終点が決まった形も同じ描画基盤へ渡せる。 |
| 32 基準7ブラシ | `referenceBrushes`。検証ページで選択し、GPU画像を個別比較。 |
| 33 Gペン | 共通筆圧曲線・人工的な入り・補正。自然な筆圧/抜きは実ペン確認。 |
| 34 丸ペン | 筆圧のある細線、小円・短線・急カーブの機械検査。描き味は実ペン確認。 |
| 35 ミリペン | 一定の太さ・濃さで同じ共通基盤を使用。 |
| 36 マーカー | 一筆の濃さを一度だけ掛ける。512/1024pxも比較。 |
| 37 鉛筆 | 連続した紙模様と筆圧による太さ/濃さ/かすれ。入力間隔による先端停滞を回避。 |
| 38 消しゴム | 硬い/柔らかい線を共通基盤で使用。 |
| 39 性能回帰 | 4/16/128/512/1024px、60/120/240/480Hzの対象条件、弱/強補正、予測、3分間。すべての組合せを網羅するものではない。 |
| 40 累積遅延 | GPU完了時の最新入力年齢を前半/後半および時間窓で比較。FPSだけを根拠にしない。画面に実際に出た時刻は未測定。 |
| 41 点/短線 | 200点の再生検査、正式描画を止めた連続24短線×7ブラシ等。 |
| 42 曲線 | 直線、小円、S字、ジグザグ、折返し、長い曲線、筆圧急変を対象化。 |
| 43 人間用ページ | `prototypes/brush-rt/dist/illustro-brush-rt.html`。平易な日本語の確認項目と結果保存。旧合格版も比較用に保持。 |
| 44 見た目の回帰 | GPU画像の位置・太さ・濃さ・終端とCPU参照を比較。人間に切替が見えないことは実機確認。 |
| 45 再現性 | 同じ入力/設定/seedで形・命令を再生成し、読み込み時に照合。 |
| 46 Undo/保存 | 取り消し、やり直し、保存、読込み、再生を検査。前の版の実際の7ブラシ保存データを追加照合。 |
| 47 範囲外 | 水彩・混色・特殊ツール・全ブラシ一覧は完成条件に含めず、拡張境界を記録。 |
| 48 過去方式 | `FAILURE_ANALYSIS.md`。失敗したCPU画素走査/表示FIFO等を実装の前提にしない。 |
| 49 実行 | 調査、共通設定、実装、Node検査、両GPU検査、性能検査、修正、再実行。結果と失敗を保存。 |
| 50 完成判定 | 実装・機械検査が成立しても、実機の軽さ維持と自然な線/見えない切替が未確認なら全体完成としない。 |
| 51 成果物 | `docs/brush-foundation`、`packages/brush-rt`、`prototypes/brush-rt`、GitHub Actionsの証拠。 |

将来の拡張契約があることと、将来の効果が実装済みであることは異なる。水彩等の新しい描画提供者には、その提供者の実装・性能・保存互換性の追加検査が必要。
