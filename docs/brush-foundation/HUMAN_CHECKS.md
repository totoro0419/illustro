# 実際のペンで確認する手順

[試し描きページ](https://illustro-realtime-brush-test.ibukioike2009.chatgpt.site)を、自分の端末・ペン・ブラウザで開く。ページ上部の旧合格版へのリンクから、同じ端末で軽さと追従を比べられる。所有者のChatGPTアカウントでアクセスする。

機械検査の結果は `VALIDATION.md` に記録している。GPU描画完了の数値から、画面に実際に出た時刻や自然な描き味を判定することはできない。

1. Gペン・丸ペンを太さ4と16で試す。弱い筆圧→強い筆圧→弱い筆圧で、直線、S字、小円、急な折り返しを描く。入りと抜きが自然か、細い部分に角や欠けがないかを見る。
2. タップと2〜5pxの短い線を続けて描く。点が消える、線が欠ける、離した後に伸びることがないかを見る。
3. 鉛筆を4・16・128で試す。模様が最初から見え、点線が後から埋まったり、離した後に濃さが変わったりしないかを見る。
4. マーカーと硬い・柔らかい消しゴムを512・1024で、4秒以上描き続ける。消しゴムは先に色を塗った場所で試す。先端が徐々に遅れる、古い線を追いかける、確定時に位置や濃さが変わることがないかを見る。
5. 「先の動きを予測して表示」を切り替え、急な方向転換と停止を試す。余分な線が残らず、訂正時の跳ねが気にならないかを見る。「手ブレ補正」も弱い設定と強い設定で比べる。
6. 取り消す・やり直す・線を保存・線を開くを試す。同じ線に戻るかを見る。ブラシを保存・読み込んだときも、筆圧・入り・抜き・Flowの設定が戻るかを見る。

「確認結果」欄に、端末、ペン、ブラウザ、描画方式、ブラシ、太さ、筆圧や補正の設定と、気になった操作を記入し、「計測結果を保存」を使う。短い動画がある場合は、ペン先と線が同時に見える状態が役立つ。

実ペンの筆圧・入り抜き、画面で見えない切替、以前の軽さ維持が確認できるまでは、全体を完成・本番採用済みと判定しない。
