## C08 塗りつぶし・線画認識

対象は最終採否で `included` の FIL-001〜010 と LIN-001〜008、計18件。初期実装・未検証は **FIL-001、FIL-004、LIN-004、LIN-005 の4/18件**。

- 色差・透明度・連続性で塗り分け、ドラッグが通った同色領域を一回のUndoで塗る。通常のレイヤー、新規レイヤー、選択マスク、透明化、保存へ接続。
- 線画を画素の濃さから境界と領域に区分し、閉じた部分と外側を色で表示。境界の追加・除去、水平垂直の短い隙間補完、参照画像を変更したときの新旧比較、同じ区分を塗りと選択で利用する処理を追加。

- コードは `apps/editor/src/fill/` と `main.ts`。最新保存位置は [C08ブランチの履歴](https://github.com/totoro0419/illustro/commits/prototype/C08/)。C08の成果は統合対象。次はC09の定規、図形、グラデーション。
