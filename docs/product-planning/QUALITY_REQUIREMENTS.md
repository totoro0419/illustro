## 今回補強した受入条件と未確定数値

[NB-01〜12](NONBLOCKING_OPERATION_CONTRACTS.md) はQR-01/04/05/06/07/22を処理別に具体化する。全件で「入力受付」「表示追従」「作品結果」「保護済時点」を別判定。**一件でも入力喪失、誤対象適用、正常保存の破壊、無断の色/深度降格、手修正消失があれば不合格**。平均FPSが高くても覆さない。

QR-19の比較は未使用文書/使用文書を同一条件で測り、起動→初筆、筆切替、p95/p99遅延、最悪停止、資源量、熱/電池、保護の遅れを記録する。初回の高度機能利用待ちも別計測し、負荷を隠して「軽い」としない。高度機能の削除を代替合格にしない。

A11-002の標的寸法は、Touchの主要制御へ原則44×44論理px以上を**設計推奨**とする。根拠はW3C WCAG 2.2 SC2.5.5 Enhanced（44 CSS px、AAA）とSC2.5.8 Minimum（24 CSS pxまたは条件付き間隔、AA）の区別。これは全規格準拠の宣言ではなく、実行形態別の単位対応/例外/等価操作を検証する。

- https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced （Target Size、Equivalent/Essential等の例外）
- https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum （Size/Spacing/Equivalent）

**未確定のまま残す項目**：端末/作品別の遅延閾値、近似プレビューの許容差、筆ごとの数値既定、容量上限、Undo保持量、自動保護最大遅れ、輸出形式ごとの全保持範囲。これらは根拠のない値で埋めず、代表作品と比較計測で閉じる。機能固有の制御/状態/失敗条件を記載したことと、これらの受入合格は別。
