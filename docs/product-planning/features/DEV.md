## 分野共通の対象と端末操作

同じ文書の意味/層/選択/Mask/履歴を維持し入口だけ端末に適応。

PCはメニュー/検索/Keyboardを併用し、Tabletはペンと指の役割を維持、Phoneは詳細を下部シートへ分割する。対象名/状態/適用と取消は同時に確認できる。複雑な点/数値の操作は拡大編集を用意。

**状態・確定の共通規則**：現在Viewport/入力構成→回転/Resize/Keyboard着脱→再配置済。機能差は対応/未対応/検証不明として示す。

共通C-01〜C-10を適用する。表示ナビ/採色/資料閲覧はどの状態でも共存。同一対象の矛盾する編集だけ適用/取消/戻るで解決し、独立対象編集と保存要求は受理する。実行方式は規定しない。

## DEV-001 — PC操作

- **目的・能力**：精密で高速に描く。キーボード/マウス/ペンタブ/トラックパッド、密度調整、複数パネル
- **制作場面**：PCで長時間描く。
- **固有設定・初期値**：マウス/ペン/Trackpad/Keyboard・密度・複数パネル。明記しない数値既定はプリセット見本と実機比較で確定し、暗黙の既定を作らない。
- **入口・直接対象・プレビュー**：デスクトップ配置と一時キー。修飾キーは高速化、同じ機能のMenu入口も提供。
- **状態と標準動作**：上記の分野共通規則を適用。固有の候補/作用範囲/対象は本項の直接操作欄で表示する。
- **確定・取消・Undo・保存再編集**：文書の意味は他端末と同一、配置のみ個人設定。確定と取消の入口は分野共通規則による。
- **他ツール・層/選択/Mask**：同じ文書の意味/層/選択/Mask/履歴を維持し入口だけ端末に適応。 ナビと資料/採色は共存し、矛盾する同対象編集だけその場で解決。
- **PC/タブレット/スマホ**：本分野冒頭の端末操作を適用。長押し/修飾キーの代替入口はメニューと検索。
- **失敗・品質の受入条件**：複数入力同時/外部画面/高DPIの座標整合を検査。通常描画への未使用機能の恒常負荷は許さず、性能はQA計測で確認する。
- **競合比較・根拠**：PR-06, CS-05（[出典台帳](../RESEARCH_SOURCES.md)、[方式比較](../COMPETITOR_RESEARCH.md)）。能力採用は上記の場面/制御を根拠とする。出典が同じ機能の存在や端末差を証明しない場合は未確認であり、Illustro案としてのみ提示。
- **推奨・未決**：採用推奨。十分に検討した採用推奨案・未承認。実機での応答性・誤操作率・画質は未検証。対応OS・実行形態は次段階で検証
