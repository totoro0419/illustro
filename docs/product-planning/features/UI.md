## 分野共通の対象と端末操作

個人Workspaceと文書のツール/対象状態を区別。レイアウトで画素/選択/Maskを変更しない。

PCは左ツール+右の伸縮Workspace、Tabletは右帯の折畳と利き手反転、Phoneは左ツール入口を残し詳細を下部シートへ。Aurora/黄橙アクセントは共通、色評価の周囲は中立。

**状態・確定の共通規則**：Panel開閉/Focus/検索/配置編集/通常制作を区別。Workspace候補はプレビュー→適用/戻す。作品の確定状態は変えない。

共通C-01〜C-10を適用する。表示ナビ/採色/資料閲覧はどの状態でも共存。同一対象の矛盾する編集だけ適用/取消/戻るで解決し、独立対象編集と保存要求は受理する。実行方式は規定しない。

## UI-001 — 明色Auroraの制作画面

- **目的・能力**：作品に集中する。左ツール・右幅調整Workspace・中央キャンバス、黄橙アクセント、色評価は中立周囲色
- **制作場面**：画面を開いて描き始める。
- **固有設定・初期値**：明るいAurora・黄橙アクセント・左ツール・右Workspace幅・中央Canvas。明記しない数値既定はプリセット見本と実機比較で確定し、暗黙の既定を作らない。
- **入口・直接対象・プレビュー**：標準Workspace。左は筆/消し/塗り/選択/変形/採色/形状、右は層と色を主入口。
- **状態と標準動作**：上記の分野共通規則を適用。固有の候補/作用範囲/対象は本項の直接操作欄で表示する。
- **確定・取消・Undo・保存再編集**：配置はWorkspace、作品画素と分離。色評価部は中立の周囲色。確定と取消の入口は分野共通規則による。
- **他ツール・層/選択/Mask**：個人Workspaceと文書のツール/対象状態を区別。レイアウトで画素/選択/Maskを変更しない。 ナビと資料/採色は共存し、矛盾する同対象編集だけその場で解決。
- **PC/タブレット/スマホ**：本分野冒頭の端末操作を適用。長押し/修飾キーの代替入口はメニューと検索。
- **失敗・品質の受入条件**：全機能専用ボタンを並べず検索から到達、要求済外観を再承認対象にしない。通常描画への未使用機能の恒常負荷は許さず、性能はQA計測で確認する。
