## 分野共通の対象と端末操作

支援表示/操作設定は作品不変。代替入力も同じCommandと対象を使う。

PCはメニュー/検索/Keyboardを併用し、Tabletはペンと指の役割を維持、Phoneは詳細を下部シートへ分割する。対象名/状態/適用と取消は同時に確認できる。複雑な点/数値の操作は拡大編集を用意。

**状態・確定の共通規則**：支援設定の元/候補→適用/戻す。フォーカス/読上げ対象と作業対象を可視化し、代替Commandは元と同じ結果。

共通C-01〜C-10を適用する。表示ナビ/採色/資料閲覧はどの状態でも共存。同一対象の矛盾する編集だけ適用/取消/戻るで解決し、独立対象編集と保存要求は受理する。実行方式は規定しない。

## A11-001 — 文字・UI・コントラスト拡大

- **目的・能力**：見やすく操作する。表示拡大で確定/取消を隠さず、色以外の状態表示
- **制作場面**：文字を大きく読む。
- **固有設定・初期値**：UI/Text倍率・高Contrast・状態記号。明記しない数値既定はプリセット見本と実機比較で確定し、暗黙の既定を作らない。
- **入口・直接対象・プレビュー**：外観・アクセシビリティ。拡大プレビューと適用、色以外のラベル/形。
- **状態と標準動作**：上記の分野共通規則を適用。固有の候補/作用範囲/対象は本項の直接操作欄で表示する。
- **確定・取消・Undo・保存再編集**：個人設定、作品不変。確定と取消の入口は分野共通規則による。
- **他ツール・層/選択/Mask**：支援表示/操作設定は作品不変。代替入力も同じCommandと対象を使う。 ナビと資料/採色は共存し、矛盾する同対象編集だけその場で解決。
- **PC/タブレット/スマホ**：本分野冒頭の端末操作を適用。長押し/修飾キーの代替入口はメニューと検索。
- **失敗・品質の受入条件**：拡大時のラベル切れ・確定/取消欠落を不合格。通常描画への未使用機能の恒常負荷は許さず、性能はQA計測で確認する。
- **競合比較・根拠**：PR-06（[出典台帳](../RESEARCH_SOURCES.md)、[方式比較](../COMPETITOR_RESEARCH.md)）。能力採用は上記の場面/制御を根拠とする。出典が同じ機能の存在や端末差を証明しない場合は未確認であり、Illustro案としてのみ提示。
- **推奨・未決**：採用推奨。十分に検討した採用推奨案・未承認。実機での応答性・誤操作率・画質は未検証。数値指針は採用実行環境で定義
