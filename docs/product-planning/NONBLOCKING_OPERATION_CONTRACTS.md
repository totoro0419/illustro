# 処理中の操作契約と受入条件

改訂：2026-10-27。ユーザー要求：描画中・描画直後・内部処理中も表示移動/拡縮/回転を不必要に待たせない。以下は製品上の推奨契約で、実現済みの報告ではない。仮線、並列処理、キャッシュなどの実装方式は選定しない。

## 全操作へ適用する意味

1. **受付、途中表示、作品確定、端末内保護、持出し保存は別状態**。受付だけで画質や保存の完了を宣言しない。
2. ナビ入力は処理完了まで受付停止しない。原画・途中線・候補・選択・制御ハンドルは同じ表示変換へ追従する。ナビ自体は作品Undoに入れない。
3. 受付した編集は対象作品/対象/参照版/作者の操作順を失わない。処理完了順で作用順を入替えない。後続筆を無言で破棄しない。依存待ちを要する場合はその操作だけ「受付済・前操作の確定待ち」と示し、指ナビと独立操作を続ける。
4. 「同じ層だから全て禁止」とはしない。独立して成立する作用か、前結果を必要とする作用かを区別。矛盾する**未確定セッション**へ別編集を始める場合だけ、その場に適用/取消/戻るを出す。すでに離筆して受理した通常筆は毎回確認させない。
5. キャンセルは当該操作の寄与だけを取り消す。後続が依存する場合は「依存する未確定操作も取消/この操作を維持」を対象名付きで示し、独立した編集を全体巻戻しで消さない。
6. 実行できない要求も無言にせず理由を表示。応答待ちを隠すために誤った結果や古い結果を最新として見せない。粗い候補がある場合は未確定/精細化中を明示し、許容誤差を実機で確認するまで画質達成としない。
7. 未確定セッションはRecoveryに保留として記録できることを要求。持出しNative保存は確定作品と保留を区別し、単なる画像書出しへ未確定候補を無言混入しない。

## 操作ごとの振る舞い

以下NB-01〜12は別々の受入試験。全件で処理直前/途中/完了直前にPan/Zoom/Rotateを挿入し、受付・初反応・追従の遅延と最終像の一致を独立測定する。

| ID / 対象 | 処理中に見えるもの・続けられる作業 | 同対象の次操作・Undo/取消 | 確定/保存の境界・不合格条件 |
|---|---|---|---|
| NB-01 ブラシ確定 BRU-008/011 | 離筆した線も作品へ追従。次筆/筆変更/採色を受理。途中表示と確定を区別 | 次筆は順序を保持。Undoは指定した一筆の寄与を戻す。次筆があるから旧筆の完了を捨てない | 位置/筆圧/入り抜き/重なりが確定前後で契約に一致。旧筆が別層へ移る、次筆欠落、ナビ停止は不合格 |
| NB-02 重い塗り FIL-001〜010 | 対象候補/参照元/進捗。別層描画・資料・色変更は継続 | 同層の後続筆も受理して順序を保つ。調整中の塗りセッションと矛盾する時だけ局所解決。取消で独立筆は残す | 開始時参照を固定。処理中の新線を境界へ無言追加しない。漏れ/作用範囲の変化を隠すのは不合格 |
| NB-03 線画領域解析 LIN-001/005 | 元線は普通に描ける。旧確認済区分と新候補を区別 | 元線変更時は候補を旧版由来と表示。手修正を上書きせず差分再検討。Undoは生成/更新を戻す | 候補採用まで旧塗り不変。古い結果を最新区分へ無言採用、既存色再割当は不合格 |
| NB-04 フィルター FX-101〜136 | 最後の確定像/現在パラメータ候補/精細化状態。独立層/資料操作可 | 新パラメータは最新の意図が分かる表示。矛盾する同対象編集だけ局所解決。取消は今回設定のみ戻す | 入力対象/Mask/順序の版を保持。途中計算が新設定を上書き、精度未対応を8bitへ無言変換は不合格 |
| NB-05 変形 TRN-001〜008 | 元像/候補/枠を一体で移動。ナビしても支点は文書座標 | 連続ハンドル操作と内部Undoを受理。同対象へ描く時だけ適用/取消/戻る、別対象編集は保持 | 一確定一全体Undo。同セッションで繰返し再サンプル劣化、取消で別層筆消失は不合格 |
| NB-06 レイヤー更新 LAY-002/003/006 | 選んだ層名/挿入先/更新状態を示す。ナビと別対象筆を受理 | 並替/合成/結合の後続要求は意図順。削除対象へ来た旧計算は別層へ移さない | 構造と見た目が同じ時点へ確定。古いサムネイルは更新中と示す。行と対象の取り違えは不合格 |
| NB-07 Undo/Redo HIS-001 | 戻す/進める操作名と未完件数。表示移動は継続 | 連打も順序を保持。未完中の新筆は要求した履歴位置の後へ作用。解釈不能なら筆開始前に理由を示し取消/待機を選べる | 履歴復元完了と表示を区別。連打欠落、作品切替先に復元、途中結果を保存済扱いは不合格 |
| NB-08 Snapshot HIS-003 | 受付時点と「固定中」。後続制作は継続 | 後続編集を固定点へ混ぜない。取消はSnapshot作成だけ。名前/メモ編集は作品と独立 | 受付時点までの受理済編集の確定を含む。未完接地筆は保留と区別。完了前に復元可能と偽らない |
| NB-09 保存 SAV-003/004 | 端末内保護/持出し保存の各時点と後続未保存量 | 描画/Undo/文書切替を受理。取消は出力だけ、編集を戻さない | 要求時点の受理済離筆まで固定。後続筆を含めたSaved印、旧正常ファイル破壊は不合格 |
| NB-10 書出し IO-002〜009 | 固定した版/形式/予定ファイルと進捗。制作継続 | 設定を変えた再出力は別要求。取消後も元編集を保持 | 通常は確定作品のみ。未確定セッションがある場合は直前確定像/先に適用/戻るを選択。UI/資料混入や部分失敗を全成功にしない |
| NB-11 資料読み込み REF-001/006 | 資料枠の読込中/失敗、作品本体は変えない | 既存資料採色/通常描画は継続。枠を閉じた旧読込結果は再出現させない | 元画像検証後のみ成功。参照不能を空白正常資料として保存しない |
| NB-12 作品切替 CAN-007 | 切替先名/読込中と、元作品の保護状態 | 元作品の処理は元へ帰属。切替を取消すと元位置へ、再切替要求は行先を表示 | 文書別のUndo/選択/保留を保持。Aの結果がBへ作用する、保護前にAを破棄するのは不合格 |

## 依存待ちを許す条件

表示操作や独立編集を止める根拠にはしない。一方、確定前の同対象結果を必要とする編集を、意味のない仮結果へ確定適用する必要はない。受付と依存の可視化、入力喪失ゼロ、順序整合、局所取消、安全な保存境界の全てを満たす場合のみ依存待ちを許容する。待機長と許容度は測定し、無制限に待たせてよい契約にはしない。

## 実機の合格線を閉じる手順

PC/ペンタブ・タブレット/ペン・スマホ/指を各条件で、短筆/長筆/大径/湿式/8bit/16bit/100層/1000層/深い効果/容量不足を組合せる。同一課題の競合測定、中央値/p95/p99/最悪停止、誤対象件数、最終画素/構造の比較を記録する。入力喪失/誤対象/正常保存破壊は一件でも不合格。遅延・画質近似・温度/電池の数値閾値は未測定のため未確定。数値を閉じるまで性能検証完了とは扱わない。
