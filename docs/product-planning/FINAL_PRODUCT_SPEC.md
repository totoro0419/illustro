## 1. 製品として確定する完成像

- 主用途：一枚絵。ペン・タッチ・マウス/キーボードから、同じ意図の操作へ到達できる。左ツール／中央広いCanvas／右可変Workspace／Quick Controller／明色Aurora＋黄橙アクセントを基本とする。
- **描画・表示操作を処理の終了待ちへ直列化しない。** 仮線／仮画像と正式結果を分ける。操作受付時刻と正式画像の完成時刻は別だが、受理済みの編集を落とさない。視覚上の重複・消失・異なる版の混在は不可。
- 画素・レイヤー・非破壊効果・変形・文字などの**編集正本**を守り、表示キャッシュ・一時プレビューとは分離する。一筆一Undo、依存関係を守った正確な履歴、保存時点と異常終了救出を優先。
- 普通の描画の負荷に、未使用の高度水彩・AI・拡張・記録処理を載せない。塗りつぶし・投げ縄・ぼかし・歪みは使った時だけ必要範囲の計算を行い、正確性を保ちつつ操作追従を先行させる。
- 下記D01/02/03/05は**この版で製品の意味を確定**する。数値・内部経路・実機閾値は後工程の設計検証事項。

## 2. D01（R10）— 色の正本・ICC・精度

**決定：作品ごとの正本色空間・精度・合成意味を持ち、入力・演算・表示・Proof・出力を別の処理段階とする。**

1. 完成形の制作色空間として **sRGB、Display P3**、チャンネル表現として **8bit整数、16bit整数、16bit浮動小数点**を扱う（既承認DEC-07）。HDR32floatとネイティブCMYK編集は別の将来比較枠で、今回の必須機能にはしない。CMYK向けProofや可能な形式への変換出力まで不要にする趣旨ではない。
2. **新規作品**は、妥当な直前条件があればそれを維持する。初めて使う場合など保存済み条件がないときは **sRGB・8bit整数**を標準とする。他の色空間・精度の選択入口を隠さない。旧「未選択時sRGB」契約を尊重する。
3. **ICCの割当と変換は別操作**。割当は画素値を保ちその解釈を変更し、変換は選んだ条件のもとで画素値を変える。未埋込・不明・非対応プロファイルを推測で正しいと扱わず、原データと前提を表示する。静かな強制変換は不可。
4. **作品の画素値と画面上の色を区別**。端末表示用変換とSoft Proof／色域警告は正本を書き換えず、元の色・採色・Undo・通常出力と混同しない。画面未校正・色域外を、色一致保証と表示しない。
5. ブラシ／レイヤー合成／フィルター／変形で、使用する色空間、転送特性、α表現、ブレンド順、量子化・丸めの規則を機能契約として定義する。**U16とF16は異なり、勝手に代用しない**。近似は一時表示でのみ許容し、正式な出力／保存へ低精度結果を紛れ込ませない。
6. **新しい作品の既定合成を勝手に「全リニア光」に置換しない。** 合成モードの再現する見た目・互換性を優先し、計算式・誤差許容値は検証時に厳密化する。失敗時は元データを保持し、Normal／8bitへ無言降格しない。

**製品の受入条件**：RGB色値、α0/半透明境界、16整数/F16、ICC割当/変換、Proof、保存・再読込・外部出力を区別して検査可能であること。実機数値精度と各形式の往復互換率は後工程で確定。

## 3. D02（R11）— 変形・非破壊編集・変形後の描画

**決定：通常の移動・回転・拡縮・パース・メッシュ・歪みは原本と変形設定を保持し、操作結果を何度も原画素へ焼き込まない。ラスタライズは明示操作に限る。**

1. 変形を複数回修正しても、原本と変形定義を再編集できる。画面ズーム／表示回転は作品の画素に反映しない。回転や移動でキャンバス枠外にある原本画素は削除しない。
2. **確定前Session中**：対象と元内容を固定し、ユーザーは自由に変形候補を修正・取消できる。UndoはSession内の直前のハンドル/歪み操作を戻す。適用後の全体Undoは一Transaction。無関係な別対象への編集は取消しても残す。
3. **変形を適用した後**：変形済みレイヤーのまま選択・描画でき、描くために自動で変形を解除／焼き込まない。標準のブラシは**見えている位置と見えている筆幅**を基準に直接操作できることを製品目標とする。ただし原本へ正しく逆写像できると断定しない。
4. 描画先の意味は明示する。**「変形後の見た目へ描く」**を既定の描画モードとし、正本と変形を維持したまま変形処理の後段に**編集可能な描画内容**として保存する。これは別の通常レイヤーが意図せず増殖することや、元画像の不可逆上書きを意味しない。ブラシ跡は現時点のDocument表示座標に属する。**以前の変形パラメータだけを後から変更した場合、この後段の筆跡は自動で元画像の動きに追従しない**ことを変形再編集時に明示する。後段内容もまとめて移動/変形したい場合はその単位全体への新しい変形を使用する。
5. **「元内容を編集」**は明示的なモードとして残し、変形の前段の原本を編集する。プレビュー上の一点から元へ一意に戻せない非線形・自己重複・退化は、逆写像で自動編集したことにしない。
6. **「上に独立レイヤーへ描く」「変形を画像に焼き込む」**は明示の選択肢として残す。通常のブラシ操作だけで新たな外部レイヤー作成・全画素焼込は起こさない。
7. 文字・ベクター・マスク／選択範囲・Pixel用途はそれぞれ固有の編集正本を保持。ドット絵には整数配置・最近傍などの画素保護経路を提供し、通常の滑らかな補間を無言強制しない。
8. 変形結果の表示キャッシュは元画像や変形値の代用正本ではない。非線形変形の完成済み表示は、変化がない限り再利用し、入力・画像・マスク・色・座標の依存が変わった必要領域のみ失効させる。

**製品の受入条件**：変形後に直接描いても線位置・幅が直感と一致し、旧原本を保持する。変形前／後のどちらへの編集か説明なしで把握でき、再変形時の筆跡の扱いを不意に変更しない。反転・折り返し・透明縁・Mask・数回の変形・Undo・Saveを検証する。後段ペイントをどう内部実装するか（分離ノード／局所差分など）は詳細設計事項。

## 4. D03（R11）— 変形中の仮画像

**決定：重い変形では、操作追従を優先する独立プレビューと正式な結果計算の分離を製品の基本挙動として採る。軽い変形では同じ体験を直接描画で実現してよい。**

- 移動・回転・拡縮など、必要な品質のまま十分軽く追従できる操作に**低画質化を強制しない**。
- Warp／Mesh／Liquify／複雑なパース等で正式画素の再計算が追いつかない場合、原本または最後に整合した評価結果から一時的な仮画像を表示し、ハンドルやペンの操作を継続できるようにする。プレビューを作るだけで重くなる端末では、より軽い直描画等の経路を選ぶ。
- プレビューは変形の現在の座標・範囲・選択に整合させる。必要なら細部精度・解像度を落としても、**正式な画素・マスク・選択・保存へ低精度結果を使用しない**。
- 正式結果の計算中でもキャンバス表示操作・別対象の編集を不必要に止めない。正式表示との切替は同一の表示世代で実施し、**空白・二重表示・古い結果の上書き**を発生させない。
- 候補Sessionの取消で元に戻り、適用済みの変形はUndo/Saveの対象版で正しく確定する。長時間の処理中には、処理中・適用中・保存完了を混同しない状態表示と取消の入口を用意する。
- 仮画像方式はR01/R02と**受理順・品質・公開・資源管理の原則を共有**し、各変形の計算アルゴリズムは独立。使用条件・補間カーネル・解像度・予算・閾値は実機比較で選定する。

**製品の受入条件**：重い変形のハンドル・指ナビが本計算待ちで固まらず、確定後の画質が低下しない。確定中のUndo・別層筆・保存の結果は正しい。どの端末でも絶対0ms遅延を実測前に保証しない。

## 5. D05（R12）— 水彩の高度機能の非重点化

**決定：水彩の高度な物理・時間進行モデルを現行製品の必須能力から除外する。** 「水彩は作り込まない」というユーザー決定を、機能単位へ反映する。

| ID | 現行製品での範囲 | 非重点／保留 |
|---|---|---|
| WET-001 ぼかし・引きずり・混色 | **維持**。通常の筆と局所混色／ぼかしで制作できる | 複雑な継続媒体解析は不要 |
| WET-002 水彩・顔料・にじみ | **簡易水彩表現のみ維持**。質感・エッジ・粒状感・筆触を描画時に確定するブラシ効果 | 水分/顔料の独立場、実時間の拡散、物理ソルバー、媒体の長期状態 |
| WET-003 濡れ表示・加水・乾燥 | **保留**。高度な濡れ状態が存在する場合の専用操作で、現行製品の必須UIにはしない | 水分表示、局所/一括加水・乾燥、染みの時間変化 |
| WET-004 拡散停止・再開 | **保留**。時間進行する拡散自体を必須化しない | 拡散の一時停止・再開・壁時計と進行状態の保存 |
| WET-005 紙・吸収・質感 | **紙目・テクスチャ・粒状感を維持**。筆/素材の設定として明示管理 | 時間進行する紙吸収の物理モデル |
| WET-006 混色・試し描き | **維持**。作品と独立したパッド/試筆 | 高度水分モデルとの連動必須を外す |
| WET-007 厚塗り・油彩・乾式 | **従来の一枚絵用の採用範囲を維持**。水彩非重点化を理由に削除しない | 専用の物理流体ソルバーまで当然必要としない |

- 既存原仕様のWET-002/003/004/005は**歴史的な提案として保持**し、本書と機能状態台帳が現行優先範囲を定める。高度な水彩を未実装でも一般のラフ/塗り/レイヤー/保存を妨げない。
- 普通の混色・水彩風描画の確定画素はUndo/Saveで再現し、アプリの非使用時やバックグラウンドで絵が自動的に変化しない。水彩の保留機能を存在するかのようにUIへ表示しない。
- 「軽量だから既存の高度水彩と完全同等」と説明しない。将来、必要性が示された時のみ別の製品判断で再導入を検討する。

## 6. 全247機能の採否と将来枠

機能の最終範囲は [FINAL_PRODUCT_SCOPE.json](FINAL_PRODUCT_SCOPE.json) を唯一の機械可読な**現行スコープ台帳**とする。旧採否は比較のため保持し、元仕様に対する有効範囲を明示する。

- **完成形の対象（通常）**：234件。既存の採用/改良推奨を現行製品の機能対象として保持する。ただし初期リリースへの同時搭載を意味しない。
- **限定対象**：2件（WET-002、WET-005）。本書で明記した簡易水彩表現／紙質感だけを対象とする。
- **保留**：10件（既存8件とWET-003/004）。本体の今の必須能力ではなく、製品価値・負荷・安全性の別判断がなければ追加しない。
- **用途全体として対象外**：1件（EXT-004の動画編集／漫画ページ管理／DTP一式）。ハーフトーン・文字・単一作品のページに便利な関連個別機能は維持する。

## 7. 塗りつぶし・投げ縄・ぼかしを軽く使うための製品要求

- **塗りつぶし（FIL）**：タップに対して塗る候補が速く見え、境界漏れや参照違いを修正可能とする。探索が遠方へ及ぶ場合は正しく範囲を拡張し、未計算領域を勝手に完成扱いしない。線画領域判断は通常の色差Fillへ強制しない。
- **投げ縄（SEL）**：囲みの輪郭は入力に追従して先行表示でき、閉じる／加算／除外／取消と既存選択の関係が明確。密度Maskやフェザー計算は必要な時に行い、取消で元選択を消さない。
- **ぼかし（WET/FX/SEL）**：必要入力域が広がる半径や非局所演算を認識する。軽いプレビューと、元精度を維持した正式結果を区別し、周辺タイル境界に色段差を出さない。
- 3機能ともR05の必要入力域、R06の表示キャッシュ、R07/08のUndoと保存の意味を守る。**どの方式が速いかは実測比較で選ぶ**。低解像度の途中結果を保存データへ混ぜない。

3. **製品仕様確定と区別する未検証**：色合成の厳密数式・精度許容、変形後筆跡の内部格納方式、仮画像採用の最適閾値、タイル幅や常駐層数、Device loss時のGPU復旧、保存APIの耐久性、PSDなどの形式互換、入力遅延／描画品質／他社優越。今の製品方針が正しいと立証したものではない。
4. **検証失敗時**：基本の正確性・応答性を満たせない実装方式は改めて比較し、やむを得ず製品体験を変える必要がある場合のみ仕様変更を別の判断として提示する。黙って機能を削除・精度降格・原本破棄しない。
