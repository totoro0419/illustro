## 2. D01確定 — 作品の色・α・精度と表示/出力

**製品上の既定と完成範囲**

- ネイティブ作品は**作品単位**で色空間・ICC・チャンネル精度・合成の意味を保持する。完成対象は**sRGB / Display P3、8bit整数 / 16bit整数 / 16bit浮動小数点**。32bit浮動小数点HDRとネイティブCMYKの編集は保留/比較対象とし、現時点の完成義務に昇格しない。既承認DEC-07と一致。
- **新規作品の既定**：前回の安全に確定した設定があればそれを提示・復元する。設定履歴が無い場合は**sRGB・8bit整数**を初期候補として表示する。ユーザーは作成前に色域/精度を変更できる。既存の「直前の安全条件」の優先を壊さない。
- **プロファイル割当と色変換は別操作**。割当は既存画素値の解釈変更、変換は色の見え方を維持するため値が変わる可能性がある処理。元ICC・入力側の不明状態・結果候補を表示し、黙って置き換えない。
- **作品・表示・Proof・出力は別**：画面表示やCMYKソフトプルーフ、色域警告は正本画素を無断変更しない。作品に対する通常採色はProofの見た目を無言で正本として採用しない。輸出時の色変換・ICC埋め込み・色/編集性の損失は明示。
- **α/合成は厳密な製品契約**：不透明度とflow、消去と透明色、Straight/Premultipliedα、グループ/clip/調整層と合成結果の意味を維持する。ブラシ・エフェクト・表示・出力で同じ作品状態から整合した結果が得られること。16bit整数と16bit floatの情報表現を同値と偽らず、自動で8bitへ降格しない。
- **線形光合成を全機能の既定に強制しない**。既存のイラスト制作での予測可能性と、モードごとの定義/互換性を優先する。モード別演算式、丸め、許容誤差、CPU/GPU一致の受入条件はD10の詳細設計と比較で確定。これらが未確認なのに外観の完全一致は保証しない。
- 普段の制作では高度な色管理UIを常時表示せず、作品属性・出力・Proofから必要時にアクセスできる。

**今回決定するのは製品意味と既定、未決の計算公式を推測で確定しない。**

## 3. D02確定 — 非破壊変形と、変形後に描く意味

**元内容は原則保持し、繰り返し変形の再サンプリング劣化を避ける。**

- 移動・回転・拡縮・反転、パース/傾斜、Warp/メッシュ/液状変形は、元の編集可能な内容と**適用中の変形設定**を別に管理する。原画像の破棄/自動ラスタライズを既定にしない。特殊条件で非破壊処理が成立しないときは、適用前に対象・代替・損失を示し、ユーザーに選択させる。
- 変形中のハンドル・タップ・数値入力・指ナビは共存し、キャンバスの表示ズーム/回転を作品内容の変形へ誤流用しない。変形セッションは**適用/取消**、セッション内Undoと作品Undoを分ける。一変形確定は原則一作品Undo。
- **変形後の見た目へペンで描けることを製品目標として確定**。通常のラスター変形レイヤーでは、描画を開始した画面上の位置・筆の見た目を優先し、原素材を破壊しない**変形結果側の修正データ**として同じ編集対象に関連付けて保存する設計を第一候補とする。UIで無関係な通常レイヤーを勝手に増殖させない。
- 変形結果への修正は変形設定そのものと別の編集データとして保持する。後からメッシュ/液状変形を修正した際に、その修正線が**無断で原画の一部に逆投影されたり、勝手に別形状へ引き伸ばされたりしない**。原本を変える「元内容を編集」操作と、見た目を変える「結果側に描く」操作を明示的に切替可能にする。
- **追従の限界**：結果側の修正は選択オブジェクトの通常の配置移動と共に移動するが、非線形Warpの制御点変更へ自動的に追従して同じ意味領域を追跡できるとは保証しない。変形設定の再編集で既存修正の位置関係が変わる場合は、修正結果を表示して確認/位置合わせできるようにする。作者の修正を黙って削除しない。
- 原内容編集では、アフィン逆写像が存在する場合でも筆径/形状/テクスチャ/選択境界の意味を個別に扱う。折返し・退化等で一意の逆写像がない場合はその経路へ無理に書かない。必要なら結果側の修正へ誘導し、**明示した焼込**を最終手段として残す。
- 文字・ベクターは編集可能な正本を保持する。ピクセルアートは整数座標と画素値保持を優先し、最近傍等の補間を明示選択可能にする。
- 変形後の正式評価像は**再生成可能なキャッシュ**。元画像・変形設定・結果側の修正・Undo情報をネイティブ保存で保持する。

**内部の補正データの配置・逆写像の具体算法は詳細設計の比較対象**。要求しているのは上記のユーザーに見える操作の意味であり、特定の実装方式が成立したという断定ではない。

## 4. D03確定 — 変形にも仮画像方式を適用する条件

**複雑な変形では、操作追従と正式計算を分離する方針を製品仕様として採用する。**

- **移動/回転/通常拡縮**：軽い幾何変換で十分な即時表示が可能なら、仮画像の粗画質化や二重描画経路を強制しない。必要に応じてそのまま変形表示する。
- **Warp・メッシュ・液状変形等の重い処理**：操作中は表示用の仮画像/簡略化した変形結果を先行させ、正式な画素は別の仕事として正確に評価する。後工程の性能検査で仮画像の固定費が上回る場合、同じ要件を満たすより軽い方法に置き換えられるようにする。
- 近似は**操作中だけ**。画像の座標/輪郭/変形対象が誤操作を誘わないこと、仮画像を正式作品・Undo・保存へ混入しないこと。粗いプレビューを完成画質として表示しない。
- **正式表示への切替は欠け・二重・誤った色濃度を発生させない**。受理済みの変形確定版と入力中の最新候補を区別し、古い計算結果が新しい作品版へ公開されない。未完の間も指ナビ/独立操作を不必要に止めない。
- キャッシュは完了した高品質な変形結果を再利用し、**毎フレームすべてのWarpを全画面再計算しない**。影響のあるタイル/入力依存域の範囲、GPU/CPU/メモリ上限は実測で選ぶ。

ここで確定するのは**重い変形に先行表示が必要な場合の振る舞い**。プレビュー倍率、内部メッシュ密度、GPU転送量、正式公開粒度、処理時間は未実測のため固定しない。

## 5. D05確定 — 水彩を作り込み過ぎない

ユーザーの明示判断「水彩は作り込まない」を最優先し、**高度な水分・顔料・吸収・時間進行を追跡する媒体シミュレーションは最終製品の必須機能から外す**。ただし、普通の一枚絵に有用な軽い表現まで削除しない。

| ID | 最終製品の範囲 |
|---|---|
| WET-001 | **採用**：ぼかし、引きずり、色を追加する混色、現在の色を馴染ませる筆。選択と透明境界を尊重 |
| WET-002 | **簡素化して採用**：軽い水彩風の色重ね、にじみ風エッジ、粒状感等のブラシ表現。継続的な水/顔料の物理状態、壁時計による拡散を必須としない |
| WET-003 | **保留**：湿潤状態の可視化、加水/乾燥/水除去専用の物理状態編集。通常の乾いたブラシ表現を阻害しない |
| WET-004 | **保留**：実時間拡散の停止・再開、媒体状態の連続シミュレーション。そもそも通常作品で常時拡散処理を起動しない |
| WET-005 | **一部採用**：紙目テクスチャ、粗さ/粒子の調整、元画素を保持した比較。高度な吸収物理・時間進行は保留 |
| WET-006 | **採用**：混色・試し描きパッド。作品本体のUndoとは独立 |
| WET-007 | **採用**：乾式、厚塗り風、かすれ、油彩風の軽量な表現。高度な3D流体/厚み物理は既定の必須範囲にしない |

元のWET-002〜005の過去要求は履歴として保持するが、**現在の実装義務はこの表を優先**する。高度WET-003/004を「今は未実装だが完成必須」とはしない。DEC-06の過去推奨「乾燥/停止の厳密分離」は高度水彩を実装する場合だけ再検討する。

## 6. 他の重要な確定契約（変更なし）

- **ブラシ・仮線・本線**：描画の仮線と正式結果を区別し、太筆や保存の処理中にもパン/ズーム/回転および次の入力を受ける。正式画質は犠牲にしない。筆は受理順で意味を保持する。パフォーマンスが無限大という保証はしない。
- **レイヤー**：直近の編集層を優先キャッシュし、選択層の上下を可能な範囲で合成。Blend/Mask/Groupで結果が変わる単純フラット化は禁止。正本レイヤーは非破壊保持。
- **塗り・選択・ぼかし**：通常Fillは高度線画解析を必須にせず、隙間候補と作者判断を共有できるときだけ参照。投げ縄の入力中は輪郭を先行表示し、マスクの重い生成を必要時へ遅らせられる構成。ぼかしは出力域と必要入力域を区別し、広い処理でもナビを妨げない。計算の軽量化は実測評価する。
- **Undo・保存**：Undoは原則一操作単位の差分結果/不変ブロック共有。ネイティブ保存は描画済み画像主体の差分保存、次回起動は通常全筆を再実行しない。クラッシュ後は最後の正常世代と保護済み差分を使う。復旧保証は記録範囲内。
- **UI**：左ツール、右の可変Workspace、Quick Controller、中央のキャンバスが基本。主要入口の位置は固定、必要時だけ補助機能を近くに出す。小画面・単指・キー・アクセシビリティで同じ必須機能へ到達可能。
- **ファイル交換**：作品原本と出力/クリップボードを分け、PSD等の交換形式は色/外観/編集性の損失を明示する。巨大ファイルは対応形式の能力に応じ段階的に読み書きする。
- **待機負荷**：高度機能未使用時は原則計算しない。通常入力・キャンバス操作・作品の正確性を優先。動画編集等、一枚絵が主目的でない大型領域は従来どおり対象外。
