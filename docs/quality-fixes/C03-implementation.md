## 作品の安全性と互換性

- 既存の `.illustro` 形式と保存先のハッシュ読戻し検証は維持。破壊的な形式移行は行わない。
- 書込みに失敗した場合も、保存済みであるように表示しない。端末のブラウザダウンロードは完了を確かめられない。
- 自動保護とファイル書出しは別機能。終了直前だけに依存しない。
- 元の調査IDの無言削除や、疑いを確定バグへ変更することは禁止。
